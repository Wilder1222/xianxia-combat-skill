# 文本回归案例

用于维护技能时核查输入约束、可见因果和时间轴。以下为人工编写并审阅的文本样例，不是独立模型盲测结果，也不是已生成视频。实际平台的时长、素材接口与画面效果需要另行确认。普通创作无需加载本文件。

## 旧友留手

请求：10 秒，旧友切磋，青衣女剑修胜出但主动留手；9:16 竖屏、水墨动画，石台上没有水体。

目标时长：10 秒。

### 片段 1（10 秒）

```text
水墨动画，9:16 竖屏，云雾中的方形石台。青衣女剑修与灰衣男剑修相距两步，各以右手持一柄长剑，左手空着。二人是旧友，此次切磋神情专注而克制。
0-3秒：灰衣剑修跨步直刺青衣剑修肩前，青衣剑修右脚侧移，以剑脊拨开来刃；镜头保留二人上身和脚步，相抵处一线淡青灵光顺剑脊散开。
3-7秒：灰衣剑修回抽长剑护在身前，青衣剑修随势踏近半步，右剑低指其持剑手，短促前送形成低位威胁；灰衣压低剑身封住来路，青衣在两剑尚未相碰时提腕变线，剑尖从降低的剑身上方转向胸前，主动止在衣襟外，没有刺入。灰衣见胸前已失去遮护，止住脚步，前脚踩起一小片石尘。
7-10秒：青衣剑修先散去剑尖灵光，再垂腕收剑，目光从凝神转为轻松；灰衣剑修低头看一眼胸前剑尖原来的位置，点头退开半步。中景看清双方各自收势，石台保持完整，云雾从台外缓缓经过。
```

审阅要点：保留用户风格与画幅；低位威胁引出压剑回应，变线利用已经出现的空隙，不靠“诱招”一词直接宣布对手失守；得势后的主动停剑保留留手因果，不能压缩成单纯刺空。无共鸣、吐血或强制同伤；无凭空水面；实体剑始终各一柄。此例为人工文字设计，变线的速度、距离和竖屏覆盖仍待视频核验。

## 连续追击

请求：12 秒，两名女剑修沿溪谷空中追击，开场已经运动，不停下蓄力，不固定左右站位，结尾仍在追逐。

目标时长：12 秒。

### 片段 1（12 秒）

```text
3D国漫CGI，16:9横屏，晨光照入有石桥的狭长溪谷。白衣与墨青衣女剑修各以右手持一柄实体长剑，以足下薄薄灵气托身飞行；墨青衣在前、白衣落后三个身位，二人沿溪水流向掠行。
0-4秒：白衣剑修在追行中挥出一道贴水的弧形剑气，墨青衣剑修倾身侧滑到桥墩外侧；剑气从她身后掠过，击中桥墩留下斜向缺口，碎石落水。双人跟拍保留桥墩与两人的绕行路线。
4-8秒：墨青衣剑修绕桥墩减速转身，足下灵气向弯道外侧展开以制动；白衣沿桥墩外侧继续追入，双方间距缩至一剑可及。墨青衣从遮挡后刺向白衣右肩，白衣压剑拨偏来刃，相抵处短促亮起，肩膀随卸力偏转，身体沿桥外侧划出弧线。
8-12秒：墨青衣剑修借相抵后分离的空隙向下游加速，白衣剑修回正身体继续追上，挥出的第二道剑气切开前方垂枝，迫使墨青衣再次降低飞行高度。镜头跟出桥洞，带缺口的桥墩留在后景，两人仍持原剑向溪谷深处飞去。
```

审阅要点：攻击迫使绕行、绕行形成反击机会；接触前有追近过程；转弯有卸力；术法剑气不新增实体剑；结尾未复位或宣告胜负。

## 观察与破阵

请求：18 秒，女剑修识破幻影阵法后从局部缺口脱身，不摧毁整座遗迹。文本预案按两段各 9 秒组织，暂不调用生成工具。

目标时长：18 秒。

### 片段 1（9 秒）

```text
3D国漫CGI，16:9横屏，黄昏古遗迹，中央圆形石台外排列四根石柱。白衣女剑修右手持一柄长剑，左手空着，站在石台中心，距北柱六步。四柱分别向近侧幻影供能，并各自维持对应方位的封路光幕，地面连接线清晰可见。
0-3秒：北柱柱基的环纹先亮，北侧持枪幻影随后凝实，踏近向女剑修胸口刺来；她侧步用长剑拨开枪尖，枪尖沿身侧划过，脚步继续向北柱靠近。镜头从柱基亮纹移到幻影的长枪，使供能次序可见。
3-6秒：女剑修再向北侧移两步，右手挥出一道细窄剑气掠向柱基；剑气擦过环纹，在石面留下切口，正在回枪的幻影手臂短暂散成雾，枪头垂下。
6-9秒：她趁幻影重新凝聚时沿北柱外侧踏近，停在柱基一剑可及的位置，剑尖对准原切口；重新亮起的环纹使幻影抬枪转向她的背侧。侧面中景同时保留切口、剑尖与身后正在转向的幻影。
```

接续状态：白衣女剑修无伤，右手原剑、左手空着；位于北柱外侧，剑尖对准柱基切口；北侧幻影在背后转向，另外三柱完整，供能仍在。下一段从此姿态继续。

### 片段 2（9 秒）

```text
3D国漫CGI，16:9横屏，黄昏古遗迹，中央圆形石台外有四根石柱。无伤的白衣女剑修在北柱外侧，右手仍持一柄长剑，左手空着，剑尖对准柱基供能环上的旧切口；北侧持枪幻影在她背后抬枪转向，北柱仍维持身旁的封路光幕；另外三柱完整并持续发光，各自的幻影与封路光幕仍在。
0-3秒：幻影朝她后背直刺，女剑修贴柱侧跨，枪尖擦过她身后的石面，刮落石屑；她借侧跨转胯，将剑尖压入旧切口，切断环纹的发光连接。
3-6秒：北柱环纹沿断口两侧熄灭，幻影手中的长枪先失去形体，随后身体散开；北侧封路光幕收缩，露出一人宽的缺口，另外三柱与远处三道幻影仍在运转。
6-9秒：女剑修持剑从北侧缺口退到阵外，肩部放松后回望仍亮着的三柱，再转身离开。镜头从柱基断口拉至中远景，保留北侧暗区与其余亮区的差别，遗迹主体完整。
```

审阅要点：9 + 9 = 18；先见供能次序，再用试探验证，再利用切口；第二段不重开对峙；结果只是北侧失效；全部关键状态在第二段独立重述。

## 盾阵偏转与脱身

请求：20 秒，花海中的两名女修，白衣剑修追击、黑衣符修借盾阵偏转脱身，展示快速结印；不受伤、不说法令。文本预案分成两段各 10 秒。

目标时长：20 秒。

### 片段 1（10 秒）

```text
3D国漫CGI，16:9横屏，黄昏花海，一条浅石沟向山谷出口延伸。白衣剑修右手持一柄长剑追向黑衣符修，黑衣符修双手空着，两人沿石沟相隔四步向出口移动。全程不说法令。
0-3秒：白衣剑修跨步斜斩，剑锋脱出一道薄弧剑气逼近黑衣符修背侧；黑衣符修侧身保持退步，左手在右掌前快速结印，右掌朝向来势，半透明圆形盾阵沿掌前展开。半身跟拍看清双手与阵纹，剑修和来袭薄弧保留在侧后景。
3-7秒：剑气击中盾阵上缘，黑衣符修右肩下沉卸力，转腕使盾面倾斜，薄弧沿弧面偏向石沟外侧，切出一条倒伏花带。镜头拉至双人中景，保留攻击被导开及符修向沟边退步的过程。
7-10秒：盾阵上缘的细纹开始断裂，黑衣符修继续侧退至浅石沟边，右掌仍向追来的剑修，脚尖转向石沟；白衣剑修持剑追至两步外，抬剑准备压向盾阵缺口。两人无伤，倒伏花带留在沟外。
```

接续状态：黑衣符修站在石沟边，身体正侧转、右掌盾阵上缘开裂；白衣剑修在两步外抬剑逼近，右手原剑；双方无伤，沟外已有倒伏花带。

### 片段 2（10 秒）

```text
3D国漫CGI，16:9横屏，黄昏花海的浅石沟边，沟外一条花带已被剑气压倒。黑衣符修无伤，身体正朝石沟侧转，右掌前的半透明盾阵上缘开裂，左手空着；白衣剑修同样无伤，在两步外以右手持一柄长剑，正抬剑逼近盾阵缺口。
0-4秒：白衣剑修踏近，剑锋压入盾阵裂口；黑衣符修顺着来力侧撤右掌，盾阵碎成局部光片，身体同时侧落入浅石沟。剑锋沿她肩外掠过，余力切断沟沿花茎，符修双脚落到低处稳住重心。
4-7秒：黑衣符修沿沟底向谷口奔出，低于花冠的身体被沟沿部分遮挡；白衣剑修收回落空的剑势，绕到可下沟的位置，循折断花茎找到去向。
7-10秒：黑衣符修从石沟拐角离开近处视野，白衣剑修到达拐角前减速，剑仍在右手。镜头留在近处已被切断的花茎与逐渐消散的盾阵碎光上，黑衣符修完成这次脱身。全程无对白。
```

审阅要点：10 + 10 = 20；手印、朝向、盾面接触、偏转和失效均可见；裂纹与倒伏花带延续；符修脱身、双方无伤；不重复开阵或使用白光强行接续。

## 短促一击

请求：6 秒，黑衣修士以一记分层掌劲破盾，守方弃盾避开，不强行反转，不破坏大环境。

目标时长：6 秒。

### 片段 1（6 秒）

```text
3D国漫CGI，16:9横屏，山门前平整石坪，黑衣修士与左手持圆盾的灰衣守卫相距一步，双方右手空着。
0-2秒：黑衣修士踏近，以右掌击中守卫胸前的圆盾中心，掌心灵力将盾面压出浅凹；守卫屈膝支撑，中景看清掌与盾的接触。
2-4秒：掌心第二股震力沿盾面展开细裂纹，守卫后脚滑退半步；最后一股短促劲力从裂口顶开碎片，守卫立即松开左手盾柄，侧滚离开掌势正前方。
4-6秒：碎盾落在两人之间，黑衣修士收掌止步，灰衣守卫在侧方以双手撑地起身，保持未受伤状态。碎片只散落在近处石坪，山门与石坪主体完整。
```

审阅要点：6 秒仅承载一记攻击及回应；三重效果各有变化；弃盾与侧滚解释避开；没有套入试探、反转或山体崩塌。

## 明确指定的共鸣同伤

请求：15 秒，旧日同门的白衣剑修与黑衣持杖修士决战；设定两件法宝近距离接触会互激反震，双方明知代价仍出手，结局同伤。保留悲剧感，但看清碰撞。

目标时长：15 秒。

### 片段 1（15 秒）

```text
3D国漫CGI，16:9横屏，暮色中的空旷石台。白衣剑修右手持银蓝灵剑，黑衣修士双手握暗红长杖，相距四步；二人曾是同门；这两件法宝在近距离接触时会互相激发反震，两人都知晓这种代价。
0-3秒：二人同时踏近，剑锋与杖端隔着半步颤动，银蓝与暗红光纹交替亮起；白衣剑修握柄的手略松又攥紧，黑衣修士沉肩压住杖身，双方继续逼近。
3-6秒：白衣剑修斜斩黑衣修士肩侧，黑衣修士横杖接住剑刃；接触处两色光纹向双方手臂反冲，二人各退半步，杖端在石台擦出短痕。中景保留兵器交点和退步，光纹只沿兵器传播。
6-10秒：白衣剑修看向对手因反震发颤的手，剑尖短暂低垂；黑衣修士却握紧长杖向前压进，她随即横剑迎上，将退步改为前踏。低位镜头看清两人的支撑脚再次进入近身距离。
10-13秒：长杖下压撞上横置剑身，银蓝与暗红灵纹在交点缠合后骤然向两侧反冲；双方手腕同时渗血，肩臂被震开，握住的兵器随身体向后退去。镜头先看清相抵，再拉至双人中景，环形气浪卷起台面尘埃。
13-15秒：二人在相距三步处屈膝稳住，仍各持原来的兵器，腕边血迹清楚；白衣剑修抬眼，黑衣修士低头避开目光，两件法宝的光纹渐暗。石台留下原来的擦痕与一圈散尘，画面在二人受伤却没有继续进攻时结束。
```

审阅要点：共鸣与同伤来自明确输入，未被优化后的通用规则排除；第一次反震建立代价，第二次出手体现人物选择；接近、相抵与分离可见；不靠吞没全画面的白光宣布结果。结尾稳住身体与腕伤仍在可以同时成立，不能把恢复站姿误写成伤势痊愈。

## 退路封闭后的回应

请求：8 秒，青衣轻剑修面对持重剑的灰衣修士，连续压力下不得一直向后轻松闪避。无伤，以轻剑修借转身恢复距离结束。

目标时长：8 秒。

### 片段 1（8 秒）

```text
3D国漫CGI，16:9横屏，石廊内青衣修士右手持细长灵剑，灰衣修士双手握一柄宽重长剑，两人相距两步，青衣修士后方一步处是石栏，左侧有廊柱。
0-3秒：灰衣修士踏近横扫，重剑带出贴着剑身的宽幅灵光，青衣修士侧退避开剑锋，后脚已抵近石栏；灰衣修士顺着横扫余势压低剑尖，用前脚止住身体继续转动，再提剑向青衣修士身前压来。
3-6秒：青衣修士已经无法继续后退，左掌展开斜向的小片盾阵接住重剑压来的剑气，右手灵剑保持在身前；盾面受压下沉，她屈膝向廊柱外侧转步，将来力引向栏外。中景保留石栏限制、盾面接触与侧向路线。
6-8秒：灰衣修士落下的剑尖划过栏外石面，双手重新提剑回防；青衣修士趁他收剑时绕至廊柱侧方，撤掌散去已开裂的盾阵，右手灵剑重新指向对手，两人恢复两步距离且均未受伤。
```

审阅要点：重剑有止势与回收，轻剑修受到退路限制后改用接挡和转步；盾阵损耗可见；恢复距离来自双方动作，不是切镜自动复位。

## 符箓消耗后的夺路

请求：12 秒，持三张符箓的白衣符修从石桥上脱身，对手为赤衣剑修。明确符箓逐张消耗，不把战斗写成无限次法术对轰。

目标时长：12 秒。

### 片段 1（12 秒）

```text
3D国漫CGI，16:9横屏，窄石桥通向山道，白衣符修右手握着三张浅金纸符，左手空着；赤衣剑修以右手持一柄长剑，从桥中央逼近，相距三步。
0-4秒：赤衣剑修挥出贴桥面的剑气，白衣符修左手从右手取出一张纸符向前展开，纸符化成薄盾挡住剑气后一起碎散；右手只剩两张纸符，白衣符修顺势退向山道，赤衣剑修继续迫近。
4-8秒：白衣符修从余下两张中取出一张贴向侧方桥栏，纸符燃尽形成一道横在追击路上的牵引线；赤衣剑修停步横剑拨断线身，线与纸灰一起消散，白衣符修趁这次停顿跨下桥头，右手余下一张。
8-12秒：赤衣剑修收剑重新追出时，白衣符修已经进入山道转弯处，她把最后一张纸符收进衣襟继续奔离。镜头从桥侧跟向山道，保留断线位置与两人拉开的距离，以符修完成这次脱身结束。
```

审阅要点：三张到两张到一张的变化对应可见消耗；挡击与截路承担不同功能；追击者主动破解，符修利用其停顿脱身；剩余符箓没有自动恢复。

## 单剑载人与离剑攻击

请求：12 秒，青衣修士全程只有一柄实体剑，先御剑追近，再以这柄剑离体拦截，最后重新御剑继续追逐。允许短暂御风承载，不增加手持副剑。灰衣修士御风飞行，持长杖格挡。

目标时长：12 秒。

3D国漫CGI，16:9横屏，开阔石庭。白衣剑修在西，右手持一柄长剑；黑衣剑修在东，右手持另一柄长剑，两人处在一步可交锋的距离。白衣可在掌前近处展开定剑环；环套住剑身后留在原位置，需要白衣持续摊开左掌维持，合拢左手则环消散。黑衣可用左掌盾承接来剑。双人中景保留双方持械手、剑柄和进退路线。

审阅要点：黑衣的剑经历仍被握住、松手但被环固定、解除后短暂下落、被白衣接住四个不同状态。白衣左掌由维持转为接物，环没有在握柄后无因继续存在；其右手原剑未消失。黑衣先用盾应对来剑再脱离被定住的兵器，缴械不等于失去全部防守能力。该例只说明指定术法下的虚构表演，不是现实夺械教程或生成实测。

## 盾与符矢耗尽，守方无伤但失去遮护

请求：8 秒，黑衣剑修只发出一枚符矢。白衣剑修的掌前薄盾挡住它，盾与符矢同时耗尽，白衣身体无伤，但须利用石柱挡住随后逼近的黑衣。双方各自右手始终持原剑，本段不再开盾、不再发射符矢，结尾仍在追击中。

目标时长：8 秒。

### 片段 1（8 秒）

```text
3D国漫CGI，16:9横屏，开阔石庭。黑衣剑修在西，白衣剑修在东，相距三步，两人各自右手持一柄长剑；白衣左掌前已展开一面朝西的薄盾。白衣东侧身后一步有一根足以遮住身体的完整石柱，柱南北两侧均能通行。本次薄盾与来袭符矢接触后会共同耗尽，之后白衣不再开盾。双人中远景保留持械手、盾面、石柱与绕行路线。
0-3秒：黑衣左手向东推出唯一一枚符矢，右手原剑留在身侧；符矢沿直线飞向白衣身前，矢尖抵上薄盾中央并停在盾面，白衣左臂承压略沉。符矢未越过盾面，身体和衣物没有被它碰到；黑衣发射后持剑向东逼近。
3-5秒：符矢从尖端逐渐溃散，薄盾的裂纹同时扩开；最后一段矢身与剩余盾纹一同散为细光并暗下。白衣收回空出的左手，右手原剑仍在，身体无伤；身前只剩逐渐散尽的光点，胸前衣袍完整。
5-8秒：白衣从身后石柱的北侧绕至柱东面，让石柱挡在自己与黑衣之间；黑衣右手持原剑，改从石柱南侧继续逼近，试图绕开遮挡。结尾白衣没有护盾、两人均无伤，原先两柄长剑完整，石柱尚未被击中，追击没有结束。
```

审阅要点：同一次交会得到三个不同结果——符矢耗尽、盾失去作用、人物无伤；白衣之后靠既有掩体改变处境，而非盾自动恢复。黑衣持剑逼近保持后续压力，没有额外符矢。柱两侧的绕行避免把人物写成直穿柱体。该例不代表所有破盾都能抵消攻击，也不代表格挡永远没有传力或代价。

## 抓腕后的局部回应与主动脱开

请求：10 秒无伤的近身争路，双方空手且没有定身、御空或瞬移能力。开场青衣右手已抓住灰衣左前臂；灰衣能用右手回应。青衣通过主动脱手绕到南侧台阶，灰衣仍追赶，不写成擒住一腕便全身僵直，也不把脱开写成击败。

目标时长：10 秒。

### 片段 1（10 秒）

```text
3D国漫CGI，16:9横屏，开阔石台南侧有下行台阶，东侧留有足够两人错身的空地。青衣修士在北、面朝南，灰衣修士在南、面朝北，相距半步；灰衣身后约一个身位就是南侧台阶。青衣右手握住灰衣左前臂，青衣左手与灰衣右手均空着，双方双脚在石台上。两人没有定身、御空和瞬移能力，石台完整。
0-3秒：青衣向北退半步，以右手牵动灰衣左前臂；灰衣跟进半步保持支撑，右掌抵上青衣左肩推挡，使青衣上身略向后让开。双人中景同时看清抓握与推肩两处接触。
3-6秒：青衣止住后撤，向东侧跨步，右手仍握着灰衣左前臂；灰衣顺着牵动转步跟上，左臂随身体转向，右掌仍贴着青衣左肩继续推挡。镜头保留南侧台阶与两人的侧移。
6-8秒：青衣先张开右手放开灰衣左前臂，再收左肩向东退开，使灰衣右掌从肩前滑离；灰衣将左臂收回身前，右掌随推势短暂前送后收回。两处接触先后解除，两人各自用脚步维持站姿。
8-10秒：青衣快步沿灰衣东侧的空地绕至其南侧，踏上台阶；灰衣转身跨步跟到台阶前，右掌重新护在身前。结尾青衣已到南侧台阶，灰衣仍在石台边追赶，双方无伤，双手已经分离。
```

审阅要点：右手抓左前臂与右掌推左肩是两组不同接点；灰衣的自由右手和脚步持续参与回应。青衣先放手再撤肩，不能第一处解除便跳过第二处；脱离路线经过已建立的东侧空地，灰衣没有暂停等待。两人始终各自落脚，不因一处抓握直接变成托举。此例只检查文字关系，不代表已取得双人抓握视频。

在仓库根目录运行 `python -X utf8 scripts/validate_repository.py` 可复查本地引用和时间轴。检查器另经错误注入验证：断层、重叠、零时长、末端错误、总时长错误、片段编号错误、缺失目标时长、提示词围栏损坏均会失败。

本地 Markdown 章节链接同时检查目标标题，包括页内跳转、跨文件跳转、中文百分号编码和重复标题编号；反引号或波浪线围栏中的示例不作为导航。标题解析针对本仓库使用的井号标题及常见行内格式，不是完整 Markdown 渲染器；下划线式标题、自定义 HTML 锚点、引用式链接和外部网页锚点不在本次支持范围。标题改名后的失效链接已有错误注入测试，链接有效仍不证明其内容或视频效果正确。

引用检查跳过 `.git`、`.local-evidence`、`__pycache__` 和构建输出 `dist` 中的 Markdown，并拒绝公开文档链接到这些目录；其余新建但尚未提交的文档仍纳入检查。插件构建时另在独立包根目录核对包内引用。这是本项目的明确目录范围，不是通用 Git 忽略规则解析器；外部网址、不支持的 Markdown 语法和攻防语义仍须另行核查。

上述执行边界为桌面推演，未调用供应商测试；本文件未提供实际视频质量证据。后续实测应保留输入、完整提示词、平台与模型信息、实际视频和逐项缺陷记录，不能用本轮文本结果替代。
