# 仙侠用词

需要补充术法形态或表达时按类别选用。术语应帮助理解动作，不要求每条提示词凑满固定数量。原创场景优先使用通用称谓和原创机制。

## 武器与行为

| 类型 | 可见动作 | 连续性要点 |
|---|---|---|
| 长剑 | 刺、挑、斩、挂、压、拨、抹 | 剑尖目标、持械手与收势清楚 |
| 长刀 | 劈切、横扫、刀背拨挡、借势回斩 | 刀势惯性影响下一招，不能无因改向 |
| 飞剑 | 离手、绕行、截击、折返、归鞘 | 区分实体飞剑与术法剑影，写出回程 |
| 长枪 | 直刺、拦拿、回抽、横扫 | 距离优势与近身受限都可成为攻防条件 |
| 符箓 | 贴附、投出、定点触发、燃尽 | 先建立附着位置与触发条件 |
| 阵盘 | 指引阵纹、改换节点、撤去供能 | 阵盘变化要对应阵中具体变化 |
| 琴、铃、扇 | 拨弦发出弧形气刃、铃波推开来袭物、扇面导流 | 描述传播和作用，不只写法器发光 |

## 能量形态与作用

| 类型 | 可见表达 | 可承担的功能 |
|---|---|---|
| 剑气 | 沿剑锋脱出的薄弧、贴地刃线、凝聚剑影 | 延伸斩击、封路、切断连接 |
| 灵压 | 衣摆贴身、脚边碎石震动、对手膝部下沉 | 限制起步、迫使改变姿势 |
| 雷法 | 电弧沿既定导体跳跃、雷束击中节点 | 打断供能或短暂压制，先建立传播条件 |
| 冰术 | 冰层沿接触面蔓延、冰棱从裂隙顶起 | 锁住落脚点、改变地面摩擦与通路 |
| 火法 | 火线沿攻击轨迹卷过、火环收拢 | 逼迫走位、切开视线，服从既定范围 |
| 护盾 | 半透明弧面受压凹陷、边缘裂纹扩大 | 阻挡、偏转、耗尽后露出防守缺口 |
| 魔气 | 雾带贴地绕行、凝成爪形后抓住兵器 | 遮挡、牵引、束缚；明确持续条件 |
| 符文 | 节点依次亮起、连接线断开、局部暗灭 | 指出供能、响应次序与失效范围 |
| 残影或幻象 | 旧路线上的轮廓渐淡、诱导形象被来刃穿过 | 标示身法或误导目标；是否可碰撞按本次设定说明 |
| 分身 | 从已建立的影印形成独立身体，沿不同路线行动后消散或回收 | 分担攻防、开路或持物；保留数量、兵器归属与退场结果 |

颜色用于区分来源，形状和运动用于表达作用。属性名称本身不证明相克。

## 打击层次

| 目标 | 可见反馈 |
|---|---|
| 接触明确 | 刀背顶住剑脊，腕部下压，响声与接触同步 |
| 格挡成立 | 来刃停在盾面前，持盾者承压后退，盾后的身体未被刃锋碰到 |
| 破盾但未命中 | 盾纹与来袭符矢一同散开，守方衣物完好，失去遮护后移向掩体 |
| 落空成立 | 刃线擦过肩外，余力击中身后石壁，身体保持未受击状态 |
| 多重力叠加 | 第一重压弯防具，第二重扩展裂纹，第三重穿过缺口 |
| 逐层破防 | 外层剑网被拨开、内层盾面开裂、守方改换防守姿势 |
| 以力破法 | 明确被破坏的法术结构以及破坏后的空隙 |
| 法宝共鸣 | 两件已设定有关联的法器同步颤动，改变轨迹或供能 |

## 环境与情绪

| 场景或状态 | 表达选择 |
|---|---|
| 水边 | 涟漪指出来势，水帘暂时遮挡，落水改变移动方式 |
| 山石 | 裂纹沿受力方向延伸，断阶改变落脚点，碎石成为遮挡 |
| 花海 | 花浪显示气劲路径，压倒区域保留，花瓣退去后露出人物 |
| 林地 | 断枝暴露追击路线，树干提供掩护，倒木封住出口 |
| 压制 | 握柄指节收紧、后脚找支撑、目光转向可退路线 |
| 犹豫 | 剑尖偏开要害，抬起的手迟一瞬落下 |
| 决断 | 视线锁定节点，主动让出侧翼换取攻击窗口 |
| 留手 | 抵近后收住剑锋，松开肩部力量，给对手收势空间 |
| 痛苦 | 呼吸断续、支撑手发颤、动作幅度减小并影响后续选择 |

## 材质与动作细节

按已有造型与当前景别选词，避免为展示材质改衣服、改机位或放慢整段。CGI 与真人质感均可使用这些细节，风格选择见[风格与材质](../formats/video-prompt-grammar.md#风格与材质)。

| 对象 | 可选短语 | 与动作的联系 |
|---|---|---|
| 皮肤与汗光 | 额头薄汗反光、下颌绷紧、眉心松开 | 只在看得见的景别表现当下压力或收势，不凭空增加伤势 |
| 布料与束带 | 厚布袖口挤皱、丝绸衣摆随转身甩开、束带稍后回摆 | 跟随接触和加减速，不另占一个停顿展示 |
| 金属与皮革 | 剑脊冷光随转腕移动、皮革握柄磨痕、护甲局部反光 | 保留原兵器和装备形制，不强制镜面倒影或碰撞必出火花 |
| 光照 | 火光映过侧脸、阵纹蓝光照亮近侧袖口 | 光源方向与明灭对应施法阶段，不把受光染色写成衣料永久变色 |
| 受力与落地 | 肩背后移、支撑脚拖出短痕、落地扬起薄尘 | 说明接触后的方向、制动与材质，不把所有落脚都写成地裂 |

## 变招与施法短语

这些短语用于展开已确定的动作，不作为必须全部填入的标签。

| 用途 | 可直接改写的可见描述 |
|---|---|
| 起手被封 | 来剑被拨向身侧，剑尖离开原刺线 |
| 临场变招 | 退步收肘，将回收中的剑转为斜挡，接住沿空隙追来的刺击 |
| 集中破防 | 放弃扫过整面护盾，沿已经张开的裂口再次送剑 |
| 吟诵同步 | 左手结印时低念“锁影成环”，末字落下，已围住目标脚边的环纹收紧 |
| 境界压制 | 来袭剑气在护罩外消散，攻方收剑后移，守方仍留在原处维持盾面 |
| 局势反转 | 将来袭光束引向残柱，借其被挡的间隙护送同伴穿过出口 |

## 指定作品时的用法

用户明确指定《牧神记》《诛仙》等作品时，可保留其指定角色、武器和招式名；将名字展开为本次镜头里的动作、形态、机制与结果。没有必要为原创人物加入原著阵营或地点。

涉及原典事实时区分小说、动画、游戏及用户自定义改编；需忠实还原却缺少依据时，查验用户提供材料或可追溯来源。不要把未经核验的连击次数、属性克制或游戏效果写成原著定论。

可选择吸收“逐层破防”“剑阵逼位”“法宝互相干扰”“有牵绊者改变落点”等方法，不整段搬用作品人物、场景和结局。记录来源的说明留在创作依据中，不挤入用户要求的纯提示词。
