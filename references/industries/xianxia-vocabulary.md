### 情感对决类（相克共鸣 / 情绪外化）

> 以下为通用模式，适用于任何相克武器/法宝的情感对决场景。原著条目作为打击感逻辑参考。

| 招式/模式 | 类型 | 打击感特征 |
|---|---|---|
| 武器共鸣感应 | 通用 | 双方相克武器接近时同时颤动嗡鸣、光芒异变，武器先于主人感应对方 |
| 共鸣爆裂 | 通用 | 相克武器碰撞时光芒暴涨交织，冲击远超正常碰撞，双方同时被震退 |
| 人器合一 | 通用 | 持器者与武器灵力融为一体，光芒吞没身影，冲天而起或全力一击 |
| 终极对撞 | 通用 | 一方施展最强招式（引天雷/万剑/极限功法），另一方以全力硬接，碰撞后同归同伤 |
| 多家功法融合 | 通用 | 同时运转两种以上不同体系功法（如道+佛+魔），攻防兼备，周身多色光芒交织 |
| 同归同伤碰撞 | 通用 | 最强一击正面碰撞后双方同时吐血倒退，不是一方胜一方败 |
| 天琊神剑 | 诛仙（参考） | 九天异铁炼制，蓝光万道，克制魔教至凶之物；出鞘如龙吟，人剑合一冲天而起 |
| 噬魂（烧火棍） | 诛仙（参考） | 黑气蒸腾、青光大盛；噬血珠红芒万丈如恶鬼啸天，与天琊互为宿缘相克 |
| 神剑御雷真诀 | 诛仙（参考） | 九天玄刹化为神雷，以剑引之；蓝光万道合成巨大光柱当头击下 |
| 三家真法融合 | 诛仙（参考） | 太极玄清道+大梵般若+噬血珠妖力同时运转，道佛魔三色光芒交织 |

### 情感对决打击感关键词

| 关键词 | 含义 | 视觉表现 |
|---|---|---|
| 共鸣爆裂 | 相克武器碰撞产生超常冲击 | 两色光芒交织缠绕，爆裂出比普通碰撞更剧烈的冲击波，双方同时震退 |
| 无情即深情 | 下手越狠情感越深 | 面部冷厉毫无留情 vs 狰狞疯狂，碰撞惨烈但不是仇恨 |
| 同归同伤 | 最强一击后双方同时受伤 | 双方同时吐血倒退，不是一方胜一方败 |
| 武器先认人 | 武器先于主人感应对方 | 武器自行颤动嗡鸣、光芒异变，主人尚未出手武器已有反应 |
| 拆毁战场 | 碰撞波及环境被拆碎 | 坚硬擂台如纸屑四散飘飞，花海被撕毁花瓣四散，声声巨响如晴天霹雳 |

## 情绪、表情与眼神

> 战斗中人物内心变化必须通过面部外化。每个 beat 应明确角色情绪状态，双方表情形成对比或呼应。

### 表情词库

| 情绪状态 | 表情描述 |
|---|---|
| 冷静审视 | 面无表情、目光沉静如水、嘴角微抿、眉头不动 |
| 震惊 | 瞳孔微缩、嘴角不自觉抽动、后退半步、呼吸一滞 |
| 隐忍 | 咬紧牙关、额角青筋跳动、双拳攥白、身体微颤但站定不退 |
| 决绝 | 目光骤然凌厉、面部线条绷紧、嘴唇紧抿成一线、眼神不再回避 |
| 狂怒 | 面目狰狞、怒目圆睁、嘴角扯出冷笑、五官因愤怒而扭曲 |
| 痛苦 | 眉头紧皱、嘴角溢血、面部肌肉抽搐、眼神涣散一瞬后重聚 |
| 释然 | 眉头舒展、嘴角微微放松、目光从凌厉转为平静、长出一口气 |
| 悲痛 | 眼眶泛红但无泪、嘴唇颤抖、面部僵硬、目光空洞望向远方 |
| 犹豫 | 目光闪烁不定、握武器的手微微松开又攥紧、面部表情一瞬的动摇 |
| 坚定 | 眼神从犹豫转为清明、握武器之手重新攥紧、面部恢复冷静 |
| 不甘 | 咬牙切齿、目光中透出不甘与执拗、身体虽退但目光不退 |
| 疲惫 | 面色苍白、呼吸粗重、汗水沿脸颊滑落、眼神疲惫但仍保持警觉 |

### 情绪演变弧线

> 情绪不是静态标签，而是随战斗进程演变的弧线。以下为常见弧线模板：

| 弧线类型 | 阶段演变 | 适用场景 |
|---|---|---|
| 冷→惊→决 | 冷静审视 → 被压制时震惊 → 爆发时目光骤变决绝 | 越级挑战、以弱胜强 |
| 隐→怒→狂 | 隐忍承受 → 怒意渐生 → 魔化暴走疯狂 | 被激怒、堕入魔道 |
| 犹→坚→释 | 出手前犹豫 → 战斗中逐渐坚定 → 碰撞后释然 | 情感对决、师门对立 |
| 敌→动→联 | 敌意对峙 → 外敌出现时动摇 → 并肩联手后和解 | 从敌对到并肩 |
| 冷→痛→疲 | 全程冷厉 → 受伤时痛苦一瞬 → 收束时疲惫但未倒 | 势均力敌的鏖战 |
