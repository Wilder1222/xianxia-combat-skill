# 视频提示词文法

## 时长与事件分配

先区分三个量：成片总时长、每次生成片段的时长、片段内事件时间窗。时间窗连续且无重叠；最后一窗结束于该段时长；所有片段的成片使用时长之和等于目标总时长。

先编排能讲清楚的事件，再分配时间，不把所有请求缩放成同一个五段故事。下表仅为文本编排示例，不代表平台支持这些生成长度：

| 成片总时长 | 可选时间窗 | 事件安排示例 |
|---|---|---|
| 6 秒 | 0–2 / 2–4 / 4–6 | 接近、格挡反击、脱离 |
| 10 秒 | 0–3 / 3–7 / 7–10 | 试探、诱出破绽、停剑留手 |
| 12 秒 | 0–4 / 4–8 / 8–12 | 追近、借地形反击、带着下一威胁移出 |
| 15 秒 | 0–3 / 3–7 / 7–11 / 11–14 / 14–15 | 适合需要完整起落的短片，也可改为更少事件 |
| 18 秒 | 单段 18 秒，或 9 + 9 秒 | 平台支持时可如此分配，破阵的观察与利用跨段延续 |
| 20 秒 | 单段 20 秒，或 10 + 10 秒 | 平台支持时可如此分配，不默认生成 30 秒 |

工具仅支持离散时长时，先求可行组合；需要裁切或重叠转场时分别注明生成时长、裁切量与成片使用时长。比如两段各 10 秒、重叠 1 秒，成片为 19 秒。平台不可满足精确时长且无法后处理时，说明限制，不默默改成片长度。

### 慢动作与成片时间

时间轴默认标记观众看到的成片时间。涉及慢镜或变速时，区分动作按原速发生的时间、播放倍率和成片占用时间；“慢动作占成片 0.2 秒”与“把原速 0.2 秒的动作放慢”不是同一预算。对选定素材作恒定倍速时，成片使用时长等于所选素材时长除以播放倍率：原速 0.2 秒以四分之一速度播放，占成片 0.8 秒。已经给定 0.8 秒成片窗口时，不能再除一次倍率。

新增停格会增加时长；停格本来就在既定窗口内时，不重复加算。渐变速度按各段实际使用时长计算或从成片核对，不能用一个未经核对的平均倍率替代。已有慢镜素材再次变速，以本次选中素材的实际时长计算；不要把剧情中的时间与素材时间混用。

输出帧率与播放速度分别处理。重采样或补帧可以在不改总时长的情况下增加帧数，不能仅凭“高帧率”宣布动作更慢、更快或接触更完整。精确变速与停格需要当前工具支持，并以输出时间戳和实际动作核验；提示词中的倍率与小数时间只是创作要求，不保证模型逐帧兑现。没有精确倍率需求时，用可读的动作阶段和成片窗口表达即可。

## 提示词组织

开头交代风格、场景、角色与起态；正文用真实时长组织事件；末尾补充必要的光影、画幅与声音要求。每个主要事件写清动作与结果，镜头和能量描述只保留帮助理解的部分。

单段输出一块完整可复制文本。跨段时，每一块重述必要身份、损伤和起态，不用“接上段”代替独立输入。默认中文描述，不在最终提示词中暴露内部字段名或工具参数。

区分内部时长规划与提交给模型的文本：用户要求精确分镜时保留时间轴；适合运动描述的图生视频可把相同事件写成自然先后关系。镜头预算仍按目标时长审阅，实际生成时长由接口确认。不要因去掉时间码就删掉来路、回应与结果，也不要声称写出时间码便能锁定实际接触帧。

参考图只引用实际存在的素材。宿主支持 `@图片N` 时按其素材顺序绑定；其他接口使用其支持的附件标识。人物、武器、场景各说明对应关系，同一附件不能在不同段变换身份。

有首帧时，以其中可见状态起动，重点描述运动与必要交互；不要反复重建已由图片确定的衣着和光线。身份图不必被当成起始姿势，多视图设定也不代表多名角色。参考分工、冲突处理和失败修正见 [素材与迭代](reference-and-iteration.md)。

## 镜头服务事件

| 信息任务 | 合适的画面 | 避免的信息冲突 |
|---|---|---|
| 接近与追逐 | 双人中远景或跟拍，保留共同地标 | 只拍脸却要求看清绕行路线 |
| 格挡与命中 | 可同时读到武器和上身的中景，必要时短暂接触特写 | 频繁切角把一次接触写成多次攻击 |
| 结印与法阵 | 半身或全身展示施术动作，再展示范围 | 只拍阵法全景，看不到其与人物的关系 |
| 破阵线索 | 局部阵纹亮灭与幻影反应有先后对应 | 只有“识破”而没有可见证据 |
| 体型差交锋 | 同框或共同地标交代比例，局部接触可追溯到巨体部位与人物位置 | 只交替双方特写却无法比较尺度，或局部放大被误当成身体变大 |
| 情绪转折 | 留手、改换目标的动作，必要时面部特写 | 大规模远景同时要求看清瞳孔细节 |
| 冲击与余波 | 接触、受力、环境传播有顺序 | 白光先吞没人物，结果只靠文字宣布 |

一个短窗口突出当前需要读懂的攻防关系，不等于只允许一人动作或一次接触。夹击与同时双挡、近身牵制与侧翼封路可以组成同一主事件；分别明确来路、目标、回应与结果。真正有先后依赖的动作按顺序写，用户要求同时发生的动作不能为了简化改成轮流出手。

镜头移动、剪辑切换与角色移动分别写清，不能把“推近镜头”写成缩短攻击距离。固定机位、长镜头、快切均可；不强制每段换机位或每击震屏。同一镜头能否读清各条攻防线，要看距离、遮挡、景别和动作关系。复合运镜按可辨的路径、阶段与终点安排，不仅凭运镜数量判错或擅自拆掉指定长镜头。

### 场景方向与画面方向

只在会影响本次动作或接续的地方说明参照，避免含混的“人物左边”：

| 参照 | 打斗中的含义 |
|---|---|
| 场景方位 | 桥北石柱、出口一侧、崖壁上方等位置关系不随机位改变；角色绕行或转向会改变其与地标的关系 |
| 人物自身左右 | 右手持剑、左肩受伤跟随该人物身体；换角度后即使投影到了画面另一侧，也不自动换手或转移伤口 |
| 当前画面左右 | 当前机位下人物与运动的画面位置；镜头绕到对侧后可以翻转，不能据此认定人物交换位置或攻击折返 |

换机位前确定当前要读懂的攻防关系，按实际空间选择相机起点、路径或切点、终点。连续绕行、沿轴观察、共同地标或适量全景都可帮助交代变化，不要求每次换边都插入停顿和全景。角色转身、相互绕过与相机越过两人连线分别处理；用户指定固定画面左右时保留该约束，自由移动时不把左右锁成全段站位。若固定站位、相机路径和全程画面左右相互矛盾，指出具体冲突，不靠镜像整幅画面、交换身份或兵器来掩盖。

### 动作阶段与切点

慢镜用于辨认关键动作，打击顿挫用于真实接触后的瞬间强调；蓄力、主动停招和剪辑冻结分别处理。用户指定接触前冻结或子弹时间时，明确尚未碰到的间隙、冻结范围与恢复时机，不提前添加命中反馈，也不把这一风格要求删掉。环绕时继承当前动作阶段与实际间距；两刃在画面上投影重叠不自动构成接触，需要结合前后层次、接点和回应判断。要求看清间隙或接触时，选择能读到该关系的角度。

整幅画面停格与人物动作冻结、镜头继续环绕是不同效果。简单重复一帧不能产生新的观察角度；后者需能生成或取得相应视角，不能仅凭后期停格声称已经实现。表现上的时间冻结也不自动赋予角色停时术法。

同一交换跨镜头时，先确定是接着发生、从另一角度重看同一瞬间，还是有意略过一段过程。接续镜头保留当前接触与分离状态；重看同一击不重复计算命中、破损或消耗；省略过程时不将后来已经形成的姿态当成省略部分的完整展示。用户要求看清的接触、分离或换位不能仅靠结果镜头交代。

## 声音与攻防事件

声音按需要加入，不为普通提示词强加配乐或完整音轨方案。先区分用户的要求：无配乐只去掉配乐；无对白不自动去掉环境音、兵器音效或喘息；角色无声则不添加该角色的台词、法令、喊叫与喘息；全静音不添加任何可听声音。没有声音也能通过轨迹、接触、受力与结果讲清攻防，不能为追求打击感覆盖静音要求。

先确定已经编排的事件，再选择有用的声音。描述声源、材质或术法性质、动作阶段及远近即可，不要求每击叠满音层。

| 画面事件 | 可选声音与对应关系 |
|---|---|
| 挥空或擦身而过 | 掠过的破风或衣料声；若随后撞墙，再为撞墙安排声音，不能提前配成人体命中 |
| 短促接触 | 声音对应接点与材质，剑杖、剑盾、肉身和术法护盾分别处理；不是所有碰撞都用金属巨响 |
| 贴刃滑动、压剑或束缚 | 滑动时可有连续摩擦，维持中的术法可有持续声；静止相抵不凭空增加刮擦，开场已相抵也不补造起始撞击。脱开后相关持续声结束，已有余振可自然衰减，不把一段压制配成多次新命中 |
| 施法与解除 | 将蓄势、发射、被挡或消散中必要的声音绑定同一声源；撤盾不自动变成爆炸，阵法无声也成立 |

法令只在本次需要时使用，词句应能在动作窗口内说完。明确谁说、说什么、随哪次结印或出手发生；能同时完成的步法、手印和短法令并行，不能让追击者停下等待整段念诵。手势本身仍须可读，长句无法容纳时先压缩非指定台词或调整编排，不吞掉用户指定的招式和结果。

有配乐时，按威胁出现、局势改变或收势选择强调点，不要求每次切镜和碰触都卡重拍。需要听清的法令或预警声优先于同时出现的装饰音层。画外预警、延续到切镜后的残响、主观失聪和刻意留白均可服务叙事，应写清用途；它们不能代替用户要求看清的接触。声音可独立成句附在对应动作之后，最终仍交付完整提示词，是否能原生生成或精确同步由平台能力与样片确认。

## 描述压缩与特效

优先顺序：用户硬约束、身份与空间、攻防因果、结果、必要镜头、术法反馈、情绪细节、装饰。超过可读负荷时先删重复氛围与特效词，不能删攻击来路或防守回应。

按信息作用判断主次，而非按词的类别删减：供能阵线、指向弱点的明灭、证明格挡的局部光纹可能就是因果证据，不能仅因属于特效而删掉；同样，用户指定的镜头和声音也不是默认可删项。先检查具体冲突：

| 冲突来源 | 优先处理 |
|---|---|
| 先后与同时混杂 | 用清楚的主语和连接关系区分；同一击的接触、受力与碎屑传播不必拆成互不相关的新招 |
| 多条攻击路线互相遮挡 | 调整允许变化的站位、轨迹或覆盖，让目标与回应可辨；保留指定的同步、人数与接触次数 |
| 同一时刻争抢不同观察尺度 | 按用户重点分配景别与细节；并非每名配角都必须有同等面部特写，也不能无说明地牺牲指定的细节 |
| 重复外观、氛围和无功能运镜过多 | 已由有效素材承担的信息简述即可；删重复措辞与装饰，保留当前动作所需的身份、空间和状态 |

压缩后仍须读得出谁在何处做什么、哪些事同时发生、哪些必须先完成、接触怎样结束，以及下一威胁。不能把连招压成“激烈打斗”，也不把多人全改成静止背景。场景确需分段时按事件与平台能力处理，不套用统一字数、每段人数或招数上限；需要改变指定时长、同步关系或单镜要求时，先指出具体冲突，不自动换成更容易实现的版本。

把抽象词改成变化：

- “力量更强”可写为“第二次相抵时护腕下沉，后脚沿地面滑退”。
- “高速交锋”可展开为“直刺被拨开，横切擦过衣带，回剑上挑迫使对手收腕”。
- “法阵破解”可展开为“供能环被切断，北侧幻影先消散，露出撤离缺口”。

保留多重力、剑气化形、法宝共鸣等特色，但为其指定对象和结果。能量形态、运动方向、作用点足够清楚后再加环境反馈。不同颜色只帮助识别，不能代替机制解释。

正向描述明确武器、身体和遮挡关系；若穿模或身份漂移出现，回到路线、接触和参考绑定修正，不能假定模型会自行处理。环境只使用已建立的水体、岩壁、林木等元素。

## 跨段接续

分段是制作边界，叙事不必每段重走试探到决胜。按节奏选择切点：持续追击或连招可在动作仍进行且状态可辨时接续，不让每段都收势站定；需要停顿时再选稳定姿态或余波。遮挡与转向也可作为切点，但不能借此丢掉用户要求看清的关键接触；白光只是一种可选转场。

在每段末尾记录并传递以下状态；前段尚未生成时标为计划，已有输出时按 [计划终态与可用结果](reference-and-iteration.md#计划终态与可用结果) 核对偏差。仅保留本场景相关项：

| 状态 | 接续内容 |
|---|---|
| 人物 | 身份、在场本体与分身、已退场者、衣着破损、伤势、表情或行动意图 |
| 位置 | 相对地标、朝向、距离、高度与当前速度方向 |
| 镜头（涉及换位时） | 相机相对地标的位置、观察方向与跟随对象，供下一段延续或明确改变视角 |
| 动作阶段 | 正在发力、相抵、抓握、托举、回收、失衡还是制动；仍有效的成对接点、支撑与防守状态，以及下一段如何继续 |
| 兵器 | 实体数量、持械手、离手飞剑位置与召回状态 |
| 术法 | 尚存护盾、在途攻击的路线与维持条件、法阵位置及附着对象、朝向、范围与已毁节点；停射后仍有效的攻击继续传递 |
| 环境 | 受损位置与范围、倒落或移动阶段、当前通路与遮挡；相关水流、烟尘、灯光与天气。表面痕迹不自动改变可通行范围 |
| 声音（需要时） | 延续中的法令、声源、余响、配乐进退与静音范围；分段不自动重播上一击或重新念咒 |
| 事件进度 | 已完成事件及其结果、未完攻击与对手回应、后段保留的关键事件 |

下一段开头重述这些必要事实，不能凭空恢复完整地形或无伤外观，也不用“速度同上段”替代可独立理解的运动描述。尾帧约束可见姿态，单张图不能充分确定运动方向和节奏；实际观察与编排假设分别说明，平台支持视频延长或运动参考时才提交相应上下文。相同描述与尾帧接续只能降低漂移风险，之后仍需检查成片切点。

已完成的同一事件不在下一段重新执行；消耗过的同一枚符、已缴落的同一柄剑不能在接缝处凭空恢复原状。拾回兵器或再次使用同一招式作为新的事件处理；用户指定回放或插叙时明确重看旧事件，不再次消耗物件或叠加伤害。

## 最后核对

核对时间轴、总时长、素材绑定、声音范围与跨段状态。再检查每个镜头是否看得见所写动作，是否用短时间承载过多先后事件。文字通过不代表视频已经表现出节奏、接触、空间、人物一致性或音画同步。
