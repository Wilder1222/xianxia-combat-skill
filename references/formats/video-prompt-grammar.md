# 视频 Prompt 文法

> 仙侠打斗视频生成 prompt 的结构规范、运镜措辞与特效描述准则。

## Prompt 结构

每条 prompt 按以下顺序组装，以逗号和分号分隔：

```
[风格定调]，[场景环境]，[角色描述]，
[beat1 时间段]：[动作 + 镜头 + 能量/环境反馈]；
[beat2 时间段]：[动作 + 镜头 + 能量/环境反馈]；
[beat3 时间段]：[动作 + 镜头 + 能量/环境反馈]；
[beat4 时间段]：[动作 + 镜头 + 能量/环境反馈]；
[beat5 时间段]：[动作 + 镜头 + 能量/环境反馈]，
[整体光影]，[氛围词]，16:9横屏，3D国漫CGI风格
```

## Beat 时间轴

| 段落 | 时间 | 功能 | 打击感阶段 |
|---|---|---|---|
| Beat 1 | 0-3s | 对峙/冲锋/入阵/蓄法 | 灵压外溢，环境初步反应 |
| Beat 2 | 3-7s | 交锋/围困/能量膨胀 | 高速碰撞，环境裂痕扩散 |
| Beat 3 | 7-11s | 转折/爆发/蓄力定格 | 力量逆转，能量可视化升级 |
| Beat 4 | 11-14s | 决胜碰撞 | 多重力叠加/天威碾压，环境重度破坏 |
| Beat 5 | 14-15s | 收束余波 | 环境破坏痕迹证明战斗烈度 |

> 若目标时长为 10s，压缩为 3 段：0-3s / 3-7s / 7-10s，保留"试探 → 高潮 → 收束"三段。
> 若目标时长 ≤15s，一次生成完整成片，使用上述 5 beat 结构。
> 若目标时长为 16-30s，拆分为 2 段 ≤15s 各自生成再拼接，每段内部仍用 5 beat 结构：
>   - 第1段末尾 beat 改为"悬念收束"（碰撞瞬间白光爆裂，不做完整收尾）
>   - 第2段起始 beat 改为"承接爆发"（从碰撞余波中接续，不做重新对峙）
>   - 拼接点选在白光/爆裂处，用光效掩盖拼接痕迹
> 若目标时长 >30s，拆分为多段 ≤15s，每段内部仍用 beat 结构，叙事弧线跨段延续。

## 实体标签写法

当使用参考图时，用 `@图片N` 引用 ImageList 中的图片：

```
@图片1 所示的青衫修士与 @图片2 所示的黑袍魔修在 @图片3 所示的悬崖山巅对峙
```

引用规则：
- `@图片1` 对应 ImageList 第 1 张图
- 在 prompt 中紧跟角色/场景名，说明该图代表什么
- 一张角色图可被多个 beat 反复引用（同一角色全程一致）

## 运镜措辞规范

每个 beat 必须包含明确的镜头运动描述。以下为标准运镜措辞：

### 基础运镜

| 运镜 | 标准措辞 | 适用场景 |
|---|---|---|
| 推近 | 中景缓慢推近至面部特写 | 对峙蓄势 |
| 急速跟拍 | 急速跟拍冲锋 | 冲锋突进 |
| 快切多角度 | 碰撞点特写快切，多角度交替 | 剑刃碰撞 |
| 拉远 | 从特写快速拉远至全景 | 力量扩散 |
| 仰拍 | 低角度仰拍 | 压迫感/被击退 |
| 俯拍 | 俯拍全景 | 阵法展开/战场全貌 |
| 背跟拍 | 背跟拍落地/收剑 | 收束结尾 |

### 高级运镜

| 运镜 | 标准措辞 | 适用场景 |
|---|---|---|
| 环绕跟拍 | 慢动作定格 + 环绕跟拍半圈 | 蓄力定格 |
| 推近至碰撞点 | 侧面全景拍轨迹，碰撞瞬间快速推近至碰撞点 | 能量对撞 |
| 震屏 | 冲击波推向镜头产生震屏 | 冲击波扩散 |
| 俯冲第一人称 | 仰拍升空转俯冲第一人称视角 | 御剑飞行 |
| 主剑视角俯冲 | 从主剑视角俯冲下坠转地面仰拍接 | 天降主剑 |
| 逐指特写 | 逐指特写弹出 + 对手反应快切 | 逐指破力 |
| 跟拍倒飞 | 镜头跟随被轰飞方快速后移 | 被轰飞 |
| 慢镜环绕 | 慢镜展示能量被吞噬/反弹 | 招式相克 |
| 法宝共鸣特写 | 双武器特写交替颤动嗡鸣，光芒交替明灭 | 武器感应 |
| 面部对切 | 双方面部特写快切——冷厉 vs 狰狞（或其他情绪对比） | 情感张力 |
| 同归倒退跟拍 | 双方同时吐血倒退跟拍，慢镜展示鲜血飞溅 | 同归同伤 |
| 天地安静 | 碰撞后突然静音，慢镜飘落碎屑/花瓣 | 余韵留白 |
| 人器合一仰拍 | 仰拍光芒吞没身影冲天而起 | 人器一体 |
| 眼神交汇特写 | 双方目光在空中相遇的慢镜特写 | 情感暗流 |
| 情绪微表情 | 面部极近特写捕捉微表情变化（瞳孔缩放/嘴角抽动/青筋跳动） | 内心外化 |

### 运镜组合原则

- 一个 beat 内可用"先……后……"连接两个运镜动作
- 相邻 beat 的运镜应有变化（不要全程同一机位）
- 节奏快的 beat 用快切、跟拍；节奏慢的 beat 用慢动作、定格、环绕
- 决胜碰撞 beat 必须有震屏或推近至碰撞点

## 特效描述规范

### 能量描述三要素

每个 beat 的能量描述需包含**形态 + 动态 + 环境反馈**：

```
[能量形态] + [能量动态] + [环境反馈]
```

示例：
- `剑身凝聚金色光芒（形态），元气暴走周身气流旋转（动态），周围空气扭曲碎石被气浪弹飞（环境反馈）`
- `七色巨剑横亘苍穹（形态），从主剑分离无数气剑锐啸而下（动态），地面被气剑轰出密集弹坑（环境反馈）`

### 打击感描述

打击感必须分层描述，不能只写"碰撞"：

| 层次 | 措辞 |
|---|---|
| 单次碰撞 | 当的一声巨响、迸发灵力光弧与火花 |
| 多重力叠加 | 多重力叠加爆发，连环爆响，冲击波层层递进 |
| 逐指破力 | 五指次第弹出逐指破力，第一指卸力第二指震筋 |
| 天威碾压 | 天威碾压不可抵挡，主剑所到之处地面尽数迸裂 |
| 魔化暴走 | 戾气如潮涌出，招招狠厉无情 |
| 法宝共鸣爆裂 | 相克武器碰撞产生共鸣，比正常碰撞更剧烈，双方同时被震退 |
| 情感拉扯 | 下手更无丝毫留情，身体微微颤抖但握武器之手稳如磐石 |
| 同归同伤 | 双方同时口喷鲜血倒退飞出，不是一方胜一方败 |
| 天地安静 | 碰撞后天地间忽然全部安静下来，慢镜飘落碎屑/花瓣 |

### 环境破坏描述

每个 beat 至少包含一项环境反馈：

| 级别 | 措辞 |
|---|---|
| 轻度 | 碎石悬浮飘起、衣袂翻飞、水面涟漪、树叶震落 |
| 中度 | 地面龟裂纹路扩散、空气扭曲、尘土飞扬、火花飞溅 |
| 重度 | 冲击波横扫、树木折断、地面掀翻、山体崩塌 |
| 拆毁级 | 坚硬擂台如纸屑四散飘飞、巨木被碰撞余波拆碎、花海被拆毁花瓣四散 |
| 天威级 | 天地变色、云层被撕裂、空间裂缝、整片区域毁灭 |

## 情绪描述规范

> 每个 beat 必须包含角色情绪/表情/眼神描述，不能只有动作和光效。

### 情绪三要素

每个 beat 的情绪描述需包含**内心状态 + 面部外化 + 眼神/肢体细节**：

```
[情绪状态] + [面部表情] + [眼神/肢体细节]
```

示例：
- `冷静审视（状态），面无表情目光沉静如水（面部），嘴角微抿握剑之手纹丝不动（肢体）`
- `决绝（状态），目光骤然凌厉面部线条绷紧（面部），嘴唇紧抿成一线不再回避对方目光（眼神）`

### 双方表情对比

双人对战时，双方表情应形成对比或呼应：

| 对比类型 | 一方 | 另一方 |
|---|---|---|
| 冷 vs 狂 | 面冷如霜、目光清冷 | 面目狰狞、怒目圆睁 |
| 痛 vs 决 | 眉头紧皱、嘴角溢血 | 目光骤变凌厉、嘴唇紧抿 |
| 犹 vs 坚 | 目光闪烁不定、手微松又攥紧 | 眼神清明、握武器之手重新攥紧 |
| 不忍 vs 决绝 | 眼神中闪过动摇 | 面部恢复冷静、出手不再犹豫 |

### 情绪演变句式

情绪必须随 beat 演变，不能从头到尾同一表情：

```
0-3s：冷静审视，目光沉静如水；
3-7s：被压制时瞳孔微缩震惊，后退半步；
7-11s：怒而凝气蓄力，目光骤然凌厉决绝；
11-14s：碰撞瞬间痛苦一瞬，但目光未退；
14-15s：从狠厉转为疲惫与释然
```

### 眼神交汇句式

```
双方目光在空中相遇，眼神碰撞仿佛火花四溅
一方目光触及对方后迅速移开
眼神交汇一瞬，复杂情感闪过——恨意中带着不舍
目光锁定对方不放，眼神中情绪翻涌但面部不动
```

## 环境互动规范

> 角色与环境必须深度互动，不能在真空中打斗。每个 beat 至少包含一项环境反馈。

### 互动类型

| 互动类型 | 描述 | 示例 |
|---|---|---|
| 灵压影响 | 角色灵力外溢直接作用于环境 | 碎石悬浮飘起、水面涟漪、树叶震落 |
| 冲击波破坏 | 碰撞产生的冲击波撕裂环境 | 地面龟裂、树木折断、山体崩塌 |
| 拆毁级破坏 | 剧烈碰撞将人造结构拆碎 | 擂台如纸屑四散、巨木被拆碎 |
| 元素互动 | 能量属性与场景元素产生化学反应 | 花瓣被气浪卷起漫天飞舞、沙尘被灵力卷成旋风、水面被冲击波激起水柱 |
| 残留痕迹 | 战斗结束后环境留下破坏痕迹 | 焦痕遍布、地面裂痕、残余光点飘散 |
| 天象变化 | 强大力量影响天象 | 云层被撕裂、天地变色、雷云密布 |

### 环境互动句式

```
灵压外溢使地面碎石悬浮飘起、衣袂翻飞
碰撞冲击波将周围花海拆毁花瓣四散飘飞
天雷降临劈开云层，雷光照亮战场
脚下地面沉降开裂，碎石被气浪弹飞
碰撞余波将坚硬擂台拆成碎片四散飘飞
花瓣被气浪卷起在空中飞舞，与两色光芒交织
```

### 环境-情绪呼应

环境变化可以与角色情绪形成呼应：

| 呼应类型 | 环境表现 | 情绪呼应 |
|---|---|---|
| 暴风骤雨 | 冲击波横扫、碎片四散 | 激烈交锋时的愤怒/疯狂 |
| 天地安静 | 碰撞后突然静音、碎屑飘落 | 碰撞后的释然/疲惫 |
| 花瓣飞舞 | 花海被气浪卷起漫天飞舞 | 情感对决中的凄美/复杂 |
| 天地变色 | 云层撕裂、天地变色 | 决胜碰撞时的天威/绝望 |

### 正向措辞（使用）

- "剑气化龙正面碰撞" — 描述发生了什么
- "冲击波推向镜头产生震屏" — 描述视觉效果
- "慢动作定格蓄力瞬间" — 描述镜头节奏
- "地面龟裂纹路扩散" — 描述环境反馈

### 避免否定式堆砌（不使用）

- ~~"不要出现现代人"~~ → 不写，用正向描述覆盖
- ~~"不能是静止画面"~~ → 写"高速交锋"即可
- ~~"避免穿模"~~ → 不写，模型自行处理

### 禁止

- 不写"高清""4K""8K"等分辨率词（分辨率由系统控制）
- 不写内部工具名或模型名
- 不写绝对路径
- 不写"上一步生成的"等隐式引用

## 风格定调句式

每条 prompt 开头必须包含风格定调：

- `3D国漫CGI风格` — 固定风格标识
- 可追加：`精致建模`、`电影级光影`、`次世代渲染质感`

## 场景描述句式

场景描述需包含地形 + 氛围 + 光线三项：

```
悬崖山巅，云海翻涌，黄昏逆光
古战场遗迹，地面刻满符文，黄昏氛围
荒野平原，雷云密布，风云变色
通天峰山巅，雷云密布，风云呼啸
仙门洞府，灵气缭绕，月下清辉
花海山谷，漫天花瓣飞舞，黄昏柔光
七里峒擂台，周围巨木搭建，灵气充沛
```

## 角色描述句式

角色描述需包含服饰 + 特征 + 武器：

```
青衫长剑修士，长发飘逸，面容冷峻
黑袍持刃魔修，周身煞气环绕
白衣仙子，手持玉笛，仙气缭绕
道袍长者，手持古剑，仙风道骨
双目赤红的魔化少年，手持烧火棍，戾气如潮
白衣持剑修士，面冷如霜，目光清冷审视
黑衣持杖修士，面色苍白眼眶泛红，嘴角挂着血丝，周身凶光围绕
```

## 光影收束句式

prompt 末尾的光影描述需包含主光源 + 色调 + 氛围：

```
金色剑气与暗紫魔气对撞色，黄昏逆光勾勒人物轮廓
蓝白灵力与赤红烈焰对撞色，雷电照亮战场
七彩流转剑光与暗紫魔气对撞色，雷电照亮战场
紫白能量交织，体积光穿透云层照亮战场
相克武器双色光芒交织对撞色（如蓝白灵光与红黑魔光），黄昏柔光映照飞舞花瓣
```

## 平台规格

| 项目 | 规格 |
|---|---|
| 画幅 | 16:9 横屏 |
| 单段时长 | 10-30s |
| 风格 | 3D国漫CGI |
| 生成方式 | ≤15s 一次生成完整成片；16-30s 拆分为 2 段 ≤15s 各自生成再拼接；>30s 拆分多段 |

## 落 prompt 前自检

- [ ] 是否以"3D国漫CGI风格"开头
- [ ] beat 时间轴是否连续无断层
- [ ] 每个 beat 是否同时有动作 + 镜头 + 能量/环境反馈
- [ ] 每个 beat 是否有明确的运镜描述（用了标准运镜措辞）
- [ ] 是否有环境破坏反馈（至少一处）
- [ ] 打击感是否分层描述（不是只写"碰撞"）
- [ ] 参考图是否用 @图片N 标注
- [ ] 是否使用了正向措辞（无否定式堆砌）
- [ ] 末尾是否有光影收束 + "16:9横屏，3D国漫CGI风格"
- [ ] 是否使用了至少 3 个仙侠专业用词
- [ ] 情感对决场景：双方面部是否对比呈现（冷厉 vs 狰狞或其他情绪对比）
- [ ] 情感对决场景：碰撞结果是否为同归同伤（双方同时倒退）而非一方胜一方败
- [ ] 情感对决场景：收束是否有情绪余韵（武器颤动呼应/表情从狠厉转为疲惫或释然）
- [ ] 每个 beat 是否包含角色情绪/表情/眼神描述
- [ ] 情绪是否有演变弧线（不是从头到尾同一表情）
- [ ] 角色与环境是否有互动（灵压影响碎石/冲击波拆毁擂台/花瓣被气浪卷起等）
- [ ] prompt 是否全中文
