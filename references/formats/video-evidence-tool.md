# 本地视频抽帧

仅在已有实际视频、需要定位接触或连续性疑点时读取。按 [素材与迭代](reference-and-iteration.md) 先提出可检查的问题，再使用 [抽帧脚本](../../scripts/sample_video.py) 生成证据。提示词创作不需要运行它。

## 使用

需要 Python 3.11 或更新版本、当前 Python 环境中的 Pillow，以及 PATH 中已有的 `ffmpeg`、`ffprobe`。脚本不安装依赖、不下载视频、不调用生成接口。输入使用本地单文件视频，输出必须是新目录。以下命令从仓库根目录执行：

```powershell
python -X utf8 scripts/sample_video.py "D:/素材/交锋.mp4" --out .local-evidence/接触复查 --start 4.5 --end 5 --stride 1
```

时间以**视频首帧为零点**，区间含起点、不含终点。清单另存源文件 PTS（显示时间戳）及时间基，方便与其他抽帧记录对齐；播放器可能采用容器或音轨起点，不能直接假定两者相同。非零首帧、可变帧率均依据实际 PTS 定位，不用“帧号除以平均帧率”计算。

默认逐帧保存请求区间内的帧。概览时可用 `--stride 12`，表示区间内每 12 帧取一帧，时间间隔可能不均匀；接触疑点改用窄区间及 `--stride 1`。默认最多保存 60 帧，可显式设置 `--max-frames 120`；超限会报错，不静默截断。脚本完整探测所选视频轨，再提取选中帧，适合本地短片；每次外部工具调用有 120 秒超时，长片应先准备可追溯的本地片段并记录原片偏移。

## 读取结果

| 文件 | 能核查什么 |
|---|---|
| `manifest.json` | 源文件与图片 SHA-256、请求区间、实际帧序号与 PTS、工具版本、是否成功创建资料 |
| `probe.json` | 容器与轨道规格、选中视频轨的完整帧时间信息 |
| `frames/` | 保存的解码 PNG 帧；保持编码画面的尺寸和方向，不补帧、不变速、不修复画面 |
| `contact-sheet.jpg` | 带帧序号及两种时间标注的缩小索引图，用于定位后再查看单帧 |
| `report.md` | 采样范围和人工观察待填位置 |

抽帧时核对解码器实际 PTS 与探测清单，并再次核对源文件指纹。时间戳缺失、重复、倒退、损坏输入、超过可确认的末端或已存在的输出目录都会报错。中途失败时已创建目录内的清单标记为 `failed`；重试使用新目录，不把残留图片当成功结果。选择首个非封面视频轨，音轨不审听；带旋转标记或非方形像素的视频还需结合元数据与播放器核对显示方式。

`artifacts_created` 只表示抽帧资料创建成功。脚本的画面、原速播放和音频审阅状态初始均为未审阅；实际查看后另写观察记录，引用具体图片和时间。区分“可见”“被遮挡”“本次未覆盖”“与要求冲突”；索引图不能证明节奏、打击声音或采样间隔内的动作。

编码画面和播放器显示可能不同：例如旋转标记为 90°、像素比例为 2:1 的 64×48 视频，导出 PNG 仍是 64×48，不能直接用索引图的宽高推断人物体型或成片构图。方向与比例信息保存在 `probe.json`；本地测试已覆盖这一组合，但不代表所有显示矩阵、镜像或播放器处理方式都已验证。

PNG 统一转换为每通道 8 位 RGB，不等于保留源视频全部色彩信息。`probe.json` 同时保存可取得的像素格式、原始位深、色彩范围、矩阵、传递函数和原色标签；缺失时保留未知。脚本未显式做 HDR 到 SDR 色调映射或显示色彩管理，不能仅凭 PNG 或 JPEG 索引图判断原片高光溢出、肤色或术法染色是否正确。需要颜色评审时另核对原片与显示流程，并标明任何转换；元数据标签本身也不保证素材正确制作。

输入是 GIF 或经过剪辑的预览时，时间戳、帧数和“逐帧”仅指该输入文件；原片可能有更多帧、不同剪辑或不同时间零点。先核对预览画面是否符合案例描述，再引用它支持相应结论。

填写人工观察时，分别记录事件阶段、具体帧或时间、直接看见的事实，以及尚不能确认的部分。疑点跨剪辑点时，采样区间同时包含切点两侧；先比较相邻帧，再决定是否需要扩大范围。多个区间有重叠时，抽帧文件数量与不同源帧数量分开统计，不能把重复保存的同一帧当作额外观察覆盖。公开文件标为高分辨率，只说明取得文件的尺寸，不证明它未经放大、补帧或后期处理。

`.local-evidence/` 已被 Git 忽略，用于本机素材与分析资料；公开研究记录仅保留来源、指纹、位置和观察边界，不附带临时访问凭据。公开文档不能用 Markdown 链接依赖该目录中的文件；必要的本机定位可写成代码格式，并说明读者需自行取得素材。仓库引用检查会跳过该目录内的笔记，但会拒绝从公开文档指向其中的链接，即使本机文件存在。工具的验证依据见 [抽帧方法调研与验证](../../research/2026-10-06-evidence-tool.md)。
