# 素材与迭代

在多参考、首尾帧、图生视频或失败样片修正时读取。通用原则沿用 [技能主体](../../SKILL.md)，具体问题按其导航读取对应编排专题。

## 先确定素材职责

| 素材用途 | 提取的信息 | 不自动继承的内容 |
|---|---|---|
| 身份与兵器图 | 稳定外观、实体道具、持握特征 | 图中静态姿势作为整段动作起点 |
| 起始画面 | 人物位置、朝向、支撑、接触关系、已发生的动势 | 与画面矛盾的默认站位 |
| 目标末帧 | 必须达到的空间关系或姿态 | 瞬间换位、物品自动回到手中 |
| 场景图 | 地形、落脚点、障碍物与光线 | 原图里与本次人物无关的身份 |
| 动作参考 | 可读的移动路线、力量起落、对手响应 | 参考角色外观、整套剧情或固定招数 |
| 运镜参考 | 相机路径、景别变化、跟随关系 | 被摄人物的全部动作与故事 |
| 分镜拼图 | 用户指定的格序、各格事件及需要保留的构图 | 把多格当成同一时刻的多人同框，或把格数直接当作已实现的镜头数 |

同一素材可被用户指定多种用途，但分别记录其控制范围。一张三视图通常属于一个角色的外观资料，不能仅因有正侧背视图就新增三个人；用户明确要求分身时，身体数量与生成阶段来自剧情要求，同一身份图可以约束多具分身的外观。未收到或未看过图片时，不把文字推测写成观察事实。

分镜拼图先确认阅读顺序与每格是连续事件、备选构图还是同步画面，不能统一按从左到右解释。格间省略的接近、接触与状态变化仍需能衔接；最后一格是计划终态，不能替代实际视频尾帧。普通分镜的边框、序号和运镜箭头属于说明，用户要求漫画分屏时才按画面元素保留。实际提交还要核对接口将整图当首帧、身份参考还是分镜控制，不能只凭附上一张多格图保证逐格执行；仅编写提示词时不强制生成角色图或分镜图。

检查分镜时逐格对照已确认的人物与兵器素材，核查数量、肢体与持物归属、接点和事件顺序；整板观感或质量分不能替代这些检查。修复单格后重看它与前后格的衔接，不因其单独好看就接受；分镜中的缺陷是否进入成片仍需分别观察。

多份素材也可以互补同一维度，例如正面身份图与背面服装图。分别指出采用的部位、属性或阶段；不要机械限制一个角色只能有一张图。若同一属性确实冲突，使用用户已指定的优先关系；未指定且会改变身份或关键动作时，指出具体冲突再确认，不折中混成第三种外观，也不整份丢弃仍有用的素材。

## 动作借鉴与当前设定的适配

先明确用户要保留的是具体动作、攻防关系、节奏还是运镜。允许借鉴时，提取“怎样接近、如何改变对手的防守、怎样结束这一拍”等关系，再按当前角色和兵器重写；要求精确复刻的动作则作为硬约束，不以“适配”为由自行替换。仅有文字描述时，按文字提供的关系工作，不虚构已经看清参考里的握法、步法或接触细节。

兵器长度、持握方式、身体结构或场地改变后，重新检查可达距离、挥动与回收空间、支撑以及对手的回应。短刀能在近身展开，不代表换成长枪后仍能沿同一大圆横扫；需要接近时补实际移动，不能靠镜头推近或拉长兵器达到接点。双方的动作一起适配，不只修改主角而保留已经对不上攻击路线的旧防守。服装、配饰和背负道具按当前用途保留，不因参考中有挥砍便自动变成可用兵器。

保留用户已设定的术法和身体能力：允许伸缩、御空或遥控兵器时按其机制解决距离与支撑，不统一改成地面招式；没有这些能力时也不能临时添加来掩盖冲突。若同时固定原动作、原间距、兵器长度和不可变场地而导致互斥，指出具体冲突，并准备能保留其余要求的候选调整；必要的选择未确定前，不声称原要求已经实现。

编排借鉴与平台动作迁移分开。前者是把可用关系写进新提示词；后者还需实际绑定参考媒体，并核实当前模式控制的是身体、表情、相机还是场景。双人接触不能只凭两条单人动作各自像参考就判为成立；迁移后仍检查双方的距离、接点、回应和共同终态。 修复控制视频里的错误时，明确允许改变的动作或接点，不能同时要求错误部分逐帧原样保留；仅改文字未必能覆盖已绑定的动作控制，须按实际接口调整控制输入并复查完整事件。文字任务不要求为此启动生成或额外准备接口不需要的素材。

## 身份与攻守分开

为每人保留一个能与素材对应的稳定称谓，辅以必要的服饰或兵器特征；同装束角色使用姓名及明确的素材绑定，不擅自改衣着来区分。每次交换都用称谓写清谁攻击、谁回应，避免连续使用含混的“他”或把“进攻者”当永久身份。

身份称谓不随攻守或画面换边而改变；持械手以人物自身左右为准。场景、身体与画面方位的区分统一见 [场景方向与画面方向](video-prompt-grammar.md#场景方向与画面方向)。不能仅靠“主角先提到”或删去身份参考来保证模型不会互换人物；是否有效须在本次接口和样片中检查。

先区分意外复制和指定的同脸人物、分身或幻象。修复意外复制时核查素材职责与预期人数；用户需要多具同貌身体时，保留其数量和独立动作，不添加全局禁同脸约束，也不以换服装来规避。具体分身状态按 [分身与多人协同](clones-and-multi-combat.md) 处理。

## 起点与终点冲突

先比较实际输入状态与用户要求：持械手、身体朝向、武器是否离手、双方距离及运动方向。若只是缺少过渡，在时长允许时补足转身、回收或换位；若存在互斥约束，指出冲突并让用户选择改素材或改要求，不擅自覆盖人物设定。

图像中已经向外飞散的碎屑、半空姿势与倾斜身体会暗示动势。需要向相反方向运动时，安排可见制动或调整输入素材；反复加“更快”“保持不变”不能解释矛盾。平台未支持中间帧时，不虚构可以提交中间帧来解决。

## 计划终态与可用结果

分开保留原计划、素材中实际可见的结果和本次选用的接续起态。能查看素材时先读取；仅有用户描述时标为用户报告，仅有文件名不能算已观察。动作与声音仍按实际检查范围记录，不能把文字计划填进未看清的部分。

| 当前情况 | 接续处理 |
|---|---|
| 尚未生成，只需完整多段提示词 | 可一次交付全部段落，内部将跨段状态作为编排计划；不要求先生成前段，也不宣称接缝已验证 |
| 已有可用片段，偏差仍在用户要求内 | 从实际起态补足必要的接近、回收或转向，再继续后续事件；同步调整剩余时间，不能瞬移回计划位置 |
| 结果违反明确的人物、能力、兵器数量、关键接触、时序或结局要求 | 不把偏差直接写入后段设定；在已授权范围内修复或选用合适素材。文字任务可交付修复与接续方案，但不能说已有可用接缝；必须改动相冲突的要求时才请用户决定 |
| 用户明确改动了原要求并采用偏差结果 | 按新要求更新后段起态、事件和时间安排；保留原提示词及观察差异，不能回写旧计划来掩盖偏差 |

“可用”表示符合当前任务要求，不等于素材中的所有内容都已核验。未涉及硬约束的小偏差可自行适配，不逐段索要批准；已被用户否定的结果不作为接续依据。对必须原地完成、必须保留的那一击或指定发生段，不能借延后、删去或改结局来宣称满足要求。

核对事件进度：已完成的结果保留，未完成的攻击继续，提前发生的事件只有在不违反明确时序、或用户已改动该要求时才能纳入后段规划。采用偏差后更新后续安排，历史计划与实际观察分别留存。

## 编排与模型文本分开

先保留一个简短内部规划：目标时长、主事件顺序、不可丢失的接触与终态。再根据输入模式组织文本：

- 文生视频：补齐辨认人物和空间所需的信息，再展开动作。
- 图生视频：沿首帧当前姿势进入动作，保留足够区分人物的称谓，描述运动、交互和结果。
- 首尾帧：检查中间路径能否到达指定末态，再写过渡；末帧只证明目标，不能证明路径成立。
- 动作或运镜参考：按明确职责适配当前人物、武器和空间；不直接换入参考片段的角色和结局。

自然先后叙述、粗时间窗或分镜分别服务不同接口与交付要求。用户要一份完整提示词时交付一份，不自动输出多个强度版本或双语包。压缩或转换后，对照已确认要求检查最终提交文本及实际绑定素材：指定接触、施术条件和接续终态不能只存在于内部规划、评分说明或未提交附件中；参数与素材已明确承载的信息无需机械重复进正文。

## 先观察，后修正

记录失败发生的原视频时间、可见现象及观察限制。将“剑锋尚未到达，人物已出现受击抽动”等具体疑点与“动作不燃”等主观感受分开；再查是预判闪避、其他已生效的力量，还是这次碰撞的反馈确实提前，不能把接触前的所有退步都判错。缺少连续视频时，静帧能帮助检查外观与接触位置，不能证明运动、节奏或声音。

粗抽帧用于定位疑点，接触短于采样间隔时可能完全漏掉。必要时查看疑点前后的连续帧及原速视频；分别标注“可见”“被遮挡”“本次未覆盖”或“与要求冲突”。被遮挡或未覆盖不能直接判成没有发生，也不能仅凭倒地结果判成接触成功。局部特写须能追溯肢体归属、目标和后续响应；放大局部本身不保证这些关系更清楚。

将一次交换的接近、接触、反馈、分离和终态分别定位，不以其中一项可见宣布整条因果通过。跨切点时成对查看切前末帧、切后首帧及各自邻帧，比较动作阶段、持握、接点、距离与破损；上身错身可见不等于足部路线也已核验。有意省略或重看同一瞬间可以成立，但须与用户的展示要求分别对照；来源提示词中的描述不是画面观察。

已有本地样片时，可按 [本地视频抽帧](video-evidence-tool.md) 保存文件指纹、实际时间戳和明确采样范围。先确认时间零点；不能将请求的抽帧时刻当成实际取到的帧，也不能用平均帧率推算可变帧率视频的位置。

| 现象 | 先核查 | 优先尝试 |
|---|---|---|
| 彼此各打各的 | 攻击与回应是否同一事件 | 逐组明确目标和结果，未限定次数时减少交换 |
| 攻守或持械归属意外互换 | 身份称谓、素材绑定与临时攻守职责是否混用，是否遗漏计划中的易手 | 固定身份称谓，按实际交换更新兵器持有者，逐次明确动作主语与目标，再检查样片 |
| 易手时物品复制、握持跳变或取物后原术无因维持 | 原件是否被双方短暂共握、释放是否发生，以及接物手是否仍承担不相容的维持动作 | 保留同一物件的接触与释放，交代原持有者空出的手、接收者原有物件和术法状态；指定分剑另按设定核查数量与用途 |
| 抓腕后全身僵住，或松一手后所有牵连同时消失 | 每个接点的双方部位、仍可用的肢体与支撑，以及是否另有定身或牵引能力 | 按现存控制编排回应，逐个解除抓握、推抵或托举；释放后双方各自继续运动，不能让手黏在已离开的身体上 |
| 换了角色或兵器后原动作无法接上 | 当前长度、握法、肢体结构、可用空间，以及用户固定的是具体动作还是作用关系 | 在允许改编的部分重建双方的接近、接触和回收；互斥的硬约束单独指出，不通过缩放兵器或新增能力掩盖 |
| 同貌身体意外增减 | 原要求的本体与分身总数、生成退场阶段，以及画面是否只是遮挡 | 按阶段明确数量和各自职责，定位多出或丢失的时刻；保留已指定分身 |
| 接触被遮住 | 是动作未接触，还是镜头与特效遮挡 | 先看连续视频，按原因补动作或改覆盖；接点与取景相互依赖时联动修正，保留无关部分 |
| 受力后自动站稳、回防或痊愈 | 改变的是移动、支撑、兵器封线还是伤势，各自恢复到什么程度 | 补当前需要的制动或回防，让剩余代价影响下一招；保留条件允许的后退中应对，不强制停稳或暗加治愈 |
| 裂痕仍在，但人物或携物穿过尚被堵住的路线 | 障碍的当前范围、倒落阶段、剩余开口与经过者姿态；区分表面损坏和真实通路变化 | 接续可行的绕行、清障或既定能力；通路原本仍可用时保留直接通过，不能为表现环境互动强加滑倒或坍塌 |
| 假动作后对手无因失守，或对隐藏动作提前作出精确反制 | 诱出的实际回应，以及角色是否已获得相应线索；不要混用观众视角与角色视角 | 按已有起手、声源、接触或感知机制补足判断与后招；对手没有上当时保留原封线，不临时赋予新能力 |
| 肢体或武器合并 | 首帧是否已经轮廓重叠、握持不清 | 修正素材或起态，再测试同一组动作 |
| 首尾帧间瞬间换位 | 目标状态是否需要未写出的动作 | 补足必要过渡，压缩非必要装饰；指定动作与接触保留，端点确实互斥时再协商调整 |
| 动作被意外放慢，停顿挤掉后招 | 播放器倍率、原片实际运动、时间窗及后期变速记录；慢镜占用的是否已是成片时间 | 先按正常播放核对原片，再修正有证据的问题；保留指定慢镜或实速，不靠改帧率、删掉关键事件或重复计算倍率凑时长 |
| 细节越多动作越少 | 时间是否足够，装饰是否争抢注意力 | 保留主要交换，减掉重复外观和无功能运镜 |
| 剑气发出后实体剑消失 | 是否混淆离手飞剑与术法投射 | 明确手中实体保持、飞出的是术法，或写明召回 |
| 施术者改招后在途攻击突然消失 | 改变的是发射、供能、操控还是攻击本身，终止条件是否已经满足 | 依设定保留仍有效的投射并交代去处；只有满足明确解除条件的术法才消散 |
| 法阵似乎跟着人物或镜头漂移 | 当前附着对象、共同地标、镜头运动与是否已有转接；纹路自旋和整个范围移动分别判断 | 用人物、法阵和地标的关系检查位置及朝向，保留指定随动能力；缺少可比较画面时标为未核验，不直接改成固定地阵 |
| 盾裂或强光之后直接宣告命中、阵毁或获胜 | 中间物是否真是防御，以及来袭物、屏障和人物各自的可见状态 | 按指定结局补足必要的接触或终态覆盖；有意在爆发中切出时可保留形式，但未看清的伤势与胜负不标为已核验 |
| 击打声与可见动作不符 | 原片接触、声音来源、遮挡，以及是否有意使用画外声或主观表达 | 按已确认事件修正错配音效或缺失动作；画面成立时优先只修声音，不能用声音补造指定接触 |

每轮优先改变动作、镜头、素材或平台参数中的一个变量组，其余能固定的条件保持一致；不能固定的随机性如实记录。若修正接点必须同时调整双方距离与取景范围，或更换首帧后原动作起态不再成立，在用户允许范围内联动修正这些直接依赖项，并说明为何不能拆开；不为了保持单变量而保留已知矛盾，也不借联动重写无关人物、招式和结局。一次成功只证明这次样片更合适；联合修正不能归功于其中某一个改动，也不证明其他场景必然改善。重复同类失败时重新核查输入与问题归类，不无限堆规则。

动作参考与结果时长不符时，先比较实际送入的参考区间、重采样或末帧延长记录、提交时长、平台支持范围、返回文件时长和后期裁切，再定位缺失的具体事件。控制素材被截短或重复末帧时，不把未输入的后招或新增停留当作原参考动作；接口处理未知则先核查，不能从输出停顿反推一定发生了末帧延长。按要求只取其中一段不属于自动漏拍；请求完整时长却提前结束，也不能仅凭短片这一现象断定动作太快或复杂，并据此擅自减速、删招或更换结局。

有声样片分别记录观看范围和实际听辨范围，定位声音发生在挥动、接触、持续相抵还是分离之后；同时保留有意留白、画外声与残响的可能。音轨存在、波形峰值或识别出的台词不能证明接触、听感或音画同步正确。只改声音且有独立音轨处理能力时，保留已经符合要求的画面；只能重新生成整段时说明画面也可能变化，不能声称做到了只改音频。没有实际听辨时，不把音画项标为通过。

## 简化时保留关键事件

先确定用户不能丢失的交锋次数、接触方式、结果、镜头形式与结局。难以执行时，可按症状减少装饰特效、非必要运镜、旁支动作或同时交互的角色数量；用户明确要求的项目不在默认删减范围内。没有规定次数时才可收束为较少的完整交换。

关键接触须保留来路、回应和结果；不能把它改成对峙、白闪后倒地或战后姿势，再声称原动作已实现。用户允许省略、写意或蒙太奇时可以采用这些表达，并准确说明保留了什么。若保留硬约束的方案持续失败，交付已完成部分及具体替代方案；需要改变明确要求时，先让用户选择。

## 留存可比较证据

维护或实测时记录：输入与素材身份、平台及具体模型、时长和画幅、完整提交文本、可固定的随机参数、返回任务编号、实际视频、原时间定位、这轮变更和观察结果。区分生成原片与经过剪辑、变速或补帧的成片；抽帧记录实际文件规格、时间戳与覆盖范围，不仅依赖网页标注。只保存非敏感信息；临时访问凭据不能写入项目。

分别说明文本是否符合要求、生成是否成功、视频是否已观看、哪项视觉问题改善或仍存在。没有样片时只完成文本方案与验证计划，不填写虚构评分。维护方法的来源和采用范围见 [调研记录](../../research/2026-10-06-combat-skills.md)，日常创作无需加载调研全文。

比较优化前后的候选时，用同一份原始需求与已确认素材约束作为依据，分别保留各自的提交文本。先核查指定人物、动作、接触、因果和结局，再评价镜头、节奏与表现力；不能按各自改写后的要求评分，让删招、换结局或新增能力掩盖偏差。先记录具体可见证据，再作判断；缺失要求与审美改善分别报告，不能用平均分抵消关键事件缺失。

静态脚本只辅助检查明确的结构规则；关键词冲突须结合动作主体、时间阶段和所指对象复核。“甲不动、乙奔跑”或“前段固定、后段推进”不因词语同时出现就互相矛盾，结构满分也不能证明远处的短剑够得着目标。不要为消除告警而删掉有效动作、镜头或堆补关键词。具体来源与复现见 [校验范围与评估调研](../../research/2026-10-06-validation-scope-and-evaluation.md)。

外部技能的作者自测、官方精选演示和本项目对照试验分别标注来源；结论限定到已知平台、模型、输入和观察范围。未知条件写明未知，不把成功选片推算为成功率，不将某条路线的失败当成所有模型的禁令。具体审阅示例见 [接触与样片证据续研](../../research/2026-10-06-contact-evidence.md)。

外部案例还须核对文字描述与实际媒体是否相符：人物类型、场景、主要事件和终态能否对应。同目录、链接有效或文件哈希一致，只能确认取得的是那份文件，不能证明案例描述正确；发现不符时保留版本与观察位置，将该媒体从相应效果证据中排除，不据此否定整个来源的所有方法。GIF、剪辑预览和原始成片分别记录，预览帧覆盖不能冒充原片连续帧覆盖。
