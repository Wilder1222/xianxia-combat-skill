## 战斗目标与局面推进

先把本场目标转成能看见的终态：夺物要看到物件到谁手中，护送要看到被保护者到达哪里，拖延要看到等待的事件终于发生。守住目标可以与个人处于下风同时成立；不要把每种胜利都改成击倒对手。

主要交换应改变后续选择，或让持续压力产生新的代价。进攻者一直占优时，可以逐步封掉退路、耗尽防具或逼近所争夺的目标，不必轮流翻盘；没有争夺目标的纯招式展示，也不强加宿敌关系或故事反转。

需要反制时，先让观众看到可利用的习惯、地形、兵器状态或能力条件，再让人物试探、利用或利用失败。前面被强调的裂口、物件或出口，应在后续动作中发挥作用、失去作用或作为明确的未解威胁保留；不能到决胜时才突然添加万能能力或刚好能用的道具。

同一招式可以再次出现。首次迫退、再次被提前封线，或借同样的起手诱出不同防守，都比单纯换名称更能表现判断变化。对手从本场能获得的起手、轨迹、声响或前次结果调整回应，不靠旁白宣布“已经识破”。不为追求零重复删掉用户指定招式，也不让已经受制的一方无条件复位重演。

诱招先写出足以被对手当作威胁的表象，再写对手实际改变或保留了什么。若成功引走防守，后招利用已经让出的路线；若对手没有按预期追挡，保留原有封线，让试探者收招、转为实攻或承担被迫退让的结果。不能只写“虚晃一招”便获得空门，也不要求每次佯攻都成功；用户已指定成败时，补足相应的可见过程。

观众看见的埋伏、背后手印或画外攻击，不自动成为场内角色掌握的信息。角色可依据视线、声音、接触中的力变或已建立的神识等感知术作出判断；既不能把看不见等同于无法察觉，也不能为一次漂亮反制临时增加全知、透视或预知能力。感知范围、遮挡和时间只补到足以决定这次回应，不要求每招都加眼神特写或内部信息表。

提前防守与提前受击分别核查：看到起手后撤步、听到预警后转盾可以发生在接触之前；由某次碰撞造成的抽动、破损或位移须发生在该作用之后。已明确先到的灵压、气流或持续束缚可以先产生效果，但须保留实际来源，不能把尚未接触的剑锋当成原因。全片静音是成片声音要求，不自动删除剧情中已指定的听觉判断。

将以上判断写成动作和结果，不把内部分析标签放进最终提示词。为表现犹豫或决断，优先选择收剑、守位、换目标等会影响事件的行为；反应特写仍需有时间与防守余地，不能让尚在飞来的攻击为表情镜头暂停。

## 招式演化与战局反转

用户需要升级或反转时，先选本次改变了哪项攻防条件，再选择表现手段；不要求每场同时具备变招、吟诵、速度反差、境界压制和反转。

| 方向 | 可见的变化 | 接续重点 |
|---|---|---|
| 临场变招 | 刺路被封后退肘回收，沿对方尚未覆盖的侧线转为挑击 | 原剑位、距离和对方追击继续有效，换招不自动命中 |
| 同体系升级 | 相同起手改为更短来路、更集中作用点或不同释放次序 | 说明为什么原防守不再足够，不只更换招式名或扩大光效 |
| 底牌与突破 | 已埋下的备用符、能力条件或领悟改变当前限制 | 展示触发、有效作用和代价；“目光骤变”本身不提供新能力 |
| 舍身或悲壮反转 | 主动挡住攻向同伴的一击，给同伴留下撤离或反击路线 | 代价与收益分别可见，不把受伤自动写成变强或同归同伤 |

跨体系融合与境界压制见[力量与法阵](powers-and-formations.md#境界压制与功法融合)；吟诵按[声音与攻防事件](video-prompt-grammar.md#声音与攻防事件)处理。正常速度的变招可以直接利用对方收势，不插入必需的凝滞；明确需要速度反差时才安排慢镜或停格，并计入成片时长。反转也可以只是抢回通路、护住目标或逼退强者，不必击败对手。

## 近战与追击

每次主要交换以 `起态 → 攻击 → 回应 → 接触或落空 → 结果 → 下一威胁` 检查。

| 要素 | 编排决策 |
|---|---|
| 可达范围 | 先交代接近、踏步或远程攻击；隔空对峙不能直接变为实体兵刃相撞 |
| 攻击目标 | 写清胸、肩、腕、腰、足下或武器；轨迹与对手回应相符 |
| 攻防接触 | 剑刃相抵、刀背拨开、盾面接住、衣角被擦过各有不同反馈 |
| 力量传递 | 护腕下沉、肩胯转动、支撑脚滑退、护盾裂开与受力方向一致 |
| 兵器连续 | 实体剑、离手飞剑、术法剑影分开计数；换手、脱手、召回明确可见 |
| 下一招 | 格挡形成空门、退步让出路线、落空暴露背侧；避免无目的碰撞后复位 |

### 近战交换示例

青衫修士踏近至长剑可及的距离，右手直刺对手胸口；黑袍刀客侧身以刀背拨开剑尖，顺势横切腰侧；修士收腹撤胯，刀锋擦断外层衣带而未击中身体；修士借后方石阶止住退势，回剑上挑刀客持刀手腕，刀客收肘退步避开。

这组动作先确定目标、回应与位移，再按需要加入剑气延长攻击范围或护体灵力卸力。剑气命中与实体剑命中分别描述。

### 角色打法与动作代价

为当前交锋选出少量真正影响决策的区别。重剑修士可以通过宽幅斩击夺取通路，轻剑修士可以利用对方收剑时改变距离；同门镜像对决则以判断和意图形成差别，不强制换成不同流派。已有角色设定优先。

| 决策 | 如何进入画面 |
|---|---|
| 偏好距离 | 谁试图接近，谁维持距离，谁利用兵器或阵法延伸范围 |
| 发力与回收 | 沉重横扫之后如何止势；飞剑离手后怎样保护施术者；轻点试探如何接下一招 |
| 防守余地 | 退路被封后改用格挡、引偏或付出代价，不能仍向同一方向轻松闪避 |
| 能力消耗 | 已燃尽符箓、破碎护盾或暂时离手的飞剑限制下一次应对；不默认所有世界都有相同耗能规则 |
| 目标取舍 | 夺路、护人、取物或获胜决定是否追击，人物不会为凑招数放弃既定目标 |

一次有效攻击后的影响持续到被可见动作解除：剑被拨到身侧后，下一拍要利用空隙、受限应对或先收剑回防；脚下支撑被毁后，转身与急停需要新的支撑或已建立的术法。

已设定疲劳时，让其影响当前可见的选择，例如缩短追击、借掩体争取间隙或改变回防方式；只补喘息而后续能力完全复位，不能表现已指定的受限状态。恢复机会由距离、阻挡或对手意图提供，不按固定交换次数让双方同时停战。不同人物的代价分别沿用设定，不把人类体力限制强加给已明确不疲劳的傀儡或术法，也不擅自将疲劳改成受伤。

这些是架空表演的可读性选择。仙侠可以借术法改变重量与惯性，但改变应有来源、作用对象和结果，不硬套现实招式或写人体伤害教程。

### 受力后的运动与恢复

重量感优先来自实际支撑、发力与回应的联系，再选衣料折皱、腰带滞后或落地扬尘作为辅助。例如踏步送肩带动刺剑，被拨开后收肘回防，袖口随前臂挤皱；不为每个动作凑固定数量的身体细节。衣摆仍在摆动不代表人物仍在位移，铠甲未凹陷也不代表没有受力。御空或术法发力沿用已建立的支撑机制，不强加蹬地。

接触结束不自动让运动停止。被向东逼退的人仍可面朝西，身体转向与移动改向也须分开；用已有地标、脚步或御空位移交代退势怎样延续、改变或停止。拉近镜头、收回兵器或恢复直立姿态，都不能单独证明人物已停止后移。

临时改招也继承当前剑位与动势：目标移出原路线后，交代原招落空、制动或如何被引成新来路，不能一句“立即反击”便把兵器重置到理想起手位。例如横斩落空后，对手已沿空隙进刺，原攻方可以退步收肘，将尚在回收的原剑转为拨挡；是否赶得上仍取决于当时距离和双方行程，不为展示连招保证每次改招都成功。

恢复只解除当前已改变的关系，不必让人物回到完整起手式：

| 当前受限之处 | 需要接续的过程 |
|---|---|
| 支撑或移动失控 | 踏步、承重、借已有支点或按既定御空能力制动；脚碰到地面不等于已经承重止势，未建立的踏板与悬浮能力不能临时补入 |
| 兵器偏离封线 | 收剑回防、顺势改变防守方向，或在当前范围内继续应对；身体站稳不等于被拨到侧面的剑已自动回到身前 |
| 伤势、装备或术法受损 | 按既有代价限制下一动作；稳住重心、再次举剑不等于伤口愈合、兵器修复或护盾补满，明确有恢复机制时再交代其起效 |

未完全恢复也可以继续行动。后退中架挡、下落中回剑或借偏转接下一招，只要当前姿态、距离与已知能力允许即可；持续追击时，不让对手无因等人物站稳，也不强制每次碰撞后都停顿。需要留手或主动停招时按人物意图表现。接触、后退、失衡、受伤和施术中断分别判断：成功格挡可能仍被迫退移，命中也不自动取消所有正在维持的能力，结果服从已建立的机制。

### 持续接触与解除

短促碰撞、沿刃滑开、持续压抵和束缚是不同状态。需要持续接触时，把双方与兵器作为同一次交互来写；不要让各自的动作独立跳到下一姿势。优先交代影响当前选择的关系：

| 判断 | 可见表达 |
|---|---|
| 哪些部位仍在接触 | 剑身相抵的位置、手握住的兵器段，或“甲右手抓乙左前臂”等成对接点；绳链与束缚阵另保留连接、附着处，接点可随滑动改变 |
| 为什么能继续施力 | 踏进维持压剑、握持拖住兵器、绳链拉紧或持续供能；一次擦碰不能无因变成黏附和拖拽 |
| 哪些动作受到限制 | 被压的剑不能直接展开独立大挥斩；双手维持的印诀不能同时改成单手防守而不影响原术，除非已有设定允许 |
| 怎样转为下一状态 | 二刃滑到末端后分开、持握松开、绳索由紧转松、供能中断后束缚失效，再进入新的攻防 |

相抵期间可以推进、退让、沿接点转向或迫近所争夺的通路。压力通过兵器、手臂与身体延续；力量更强的一方可以站稳，较弱一方退移，不要求双方等幅后退，也不要求地面必然开裂。已有御空、卸力或阵法承载按其机制表现，不额外套用地面支撑。

区分第一次碰上的冲击与后续持续压力。后续可表现剑身沿刃滑动、手臂逐渐下沉或退路缩短，不必反复写新的爆点、击打声和震屏；压力变化后才写相应的新反馈。持续接触可以产生位移、开路、转向或释放；用户需要僵持时，也可通过守住通路、同伴完成任务或施力变化说明作用，不强制每秒移动接点。

第三人或外来攻击介入时，先判断是否改变了原接触与维持条件，再写两名原参与者各自的下一动作。被迫松开的压剑、被打断的供能与主动解除要有不同原因和结果；不能只让受控者恢复自由，却让控制者仍维持原姿势、原力量和原目标。

### 抓握、牵引与抛掷

身体抓握先写清谁的哪只手接触对方哪里，再写受限的动作。抓住一只腕不自动锁住全身；其余肢体按当前姿势、距离和其他控制保留可用回应，也不保证任何姿态下都能反击。抓衣料与抓手臂分开，依已知材质和握持表现牵动、滑脱或破损，不为便于脱身临时让衣料断开。明确的全身定身按该能力处理。

牵引、托举或共同转动时，保留双方的相对位置、接点和承重变化。抓握者的手随被握部位移动，不能在身体已分开后仍隔空黏住原处；被带动者可以跟步、抵挡或用既有能力应对。要表现提离地面，交代原有支撑如何被替代；首帧已经托举或腾空时从当前阶段继续，不强制重演抓起。依据画面需要保留能看清双方承托和位置的覆盖，不用手部特写独自证明整个人已被举起。

逐个处理接点的解除：一手松开，另一手、身体承托或绳索仍有效时，剩余牵连继续存在。真正离手后，受抛者沿已经形成的方向继续运动，再按落地、碰撞或既有御空能力改变；施力者的手臂也转入回收或下一动作。仍抓着腕或连着绳索的摆荡属于持续牵引，不能同时写成完全自由飞行，也不为统一格式强制松开所有接点。隔空摄人、御空制动等明确能力不必补造实体抓握或落地过程；非接触作用与身体代价分别按设定处理，既不因隔空而删掉指定的吃力与支撑，也不强加所有术法都必须承受重量反作用。

### 持握、缴械与易手

追踪的是同一件兵器或道具，而非永远不变的持有者。主动交付、被迫松手、双方争握、抛接与落地后拾取分别写清接触和释放；不强制每次易手都先落地，也不能用切前甲持有、切后乙持有代替用户要求看清的夺取过程。双方短暂握住同一件物品时仍只有一件；另一只手只是触到物件，并不证明原持有者已失去控制。

接物所用的手及当时的动作要能相容。若左掌正维持必须连续摊掌的护盾，接剑前须解除、换用已允许的维持方式或另选承接办法；右手原有兵器也要有去处。明确允许兼持、分指施术或自主护盾时按该设定安排，不套用一只手只能承担一种用途的硬限制。被夺走或掉落的兵器继续保留位置、方向和状态，下一拍不能在原主手中复原。

接住实体与取得术法控制权分别判断。已绑定的飞剑能否被原主继续操控、夺剑是否同时断契，取决于当前设定；不默认握住剑柄就获得使用资格或消除远程威胁。缴械后仍按已知能力编排空手、法术、撤退或争夺，不能自动将“兵器离手”写成整场获胜。

### 速度、密度与烈度

“更快”先辨别是单招运动被拖长还是招间无功能停顿，分别调整起落速度或接招关系；“交锋更多”增加有回应且改变攻防关系的完整交换；“力量更重”通过受力和后续选择体现。剪辑更快与人物运动更快分别处理。不要用固定每秒镜数、起手毫秒数或不断增加微动作同时替代这些需求；改变节奏时仍保留关键接触与结果。利用对手回收空隙时，应让下一招发生在其回收尚未完成的过程中，不能先写双方复位，再宣称空隙仍在。成片时间与原速验收见[慢动作与成片时间](video-prompt-grammar.md#慢动作与成片时间)。

## 情绪与结局

情感是战斗选择的原因。人物关系、武器关系与结局分别决定，最后组合。

| 关系或动机 | 可见选择 | 可选结果 |
|---|---|---|
| 旧友切磋 | 剑尖抵近咽喉时主动偏开，另一方停下追击 | 分出胜负、相视收剑 |
| 师徒阻拦 | 专攻持械腕与落脚点，避免要害 | 缴械、放行、被迫突破 |
| 宿敌知己 | 识别惯用招式后改变节奏，逼对方亮出新招 | 单方胜出、同伤、暂时撤离 |
| 有牵绊但立场对立 | 迟疑错失先机，或改变致命攻击的落点 | 受伤退走、保护第三人、外部中断 |
| 从敌对到并肩 | 共同威胁出现后，一人挡击，另一人顺势补位 | 联手脱险，无需武器自动相生 |

“武器共鸣—无情交锋—同归同伤”保留为可选悲剧模式，仅在关系、武器设定与预期结局适配时使用。共鸣也可用于相互识别、互相干扰或联合增幅；先给出设定依据。

情绪放在有拍摄空间的关键转折：出手前的手指收紧、受伤后再度锁定目标、停剑时松开的眉心。全景用身体选择表现，特写再承担微表情。
