## 双人对决

**核心叙事**：试探摸底 → 一方力量压制 → 被压制方爆发底牌 → 招式相克决胜 → 余波收束

**打击感模式**：多重力叠加 + 招式相克

**参考原典**：
- 牧神记秦牧 vs 傅庭岳：刀法越挥越重，每刀蕴藏力量递增，从对方能挡到挡不住
- 牧神记秦牧 vs 魔猿：弹指惊雷琵琶手五指次第弹出，逐指破力
- 诛仙张小凡 vs 陆雪琪：烧火棍与天琊神剑碰撞，擂台被拆成碎片

### 15s beat 结构（单段）

| 时间段 | 动作 | 镜头 | 能量与环境反馈 |
|---|---|---|---|
| 0-3s | 双方对峙，灵压外溢使碎石悬浮飘起、衣袂翻飞。一方率先拔剑冲锋，剑破空发出尖啸 | 中景缓慢推近至面部特写，随后急速跟拍冲锋 | 灵力外溢可视化，地面碎石悬浮，衣袂翻飞，水面涟漪 |
| 3-7s | 剑刃高速碰撞交锋，攻守快速转换。每次碰撞迸发灵力光弧与火花，剑气轨迹残留空中。一方逐渐被压制，对方力量越打越重 | 碰撞点特写快切，多角度交替：碰撞特写→全景交锋→侧面跟拍 | 每次碰撞火花飞溅+灵力光弧，地面出现裂痕并逐渐扩散，空气震荡 |
| 7-11s | 被压制方怒而凝气蓄力，爆发底牌——剑身凝聚光芒/元气暴走/法印膨胀。慢动作定格蓄力瞬间，周围空气扭曲 | 低角度仰拍蓄力方，慢动作定格 + 环绕跟拍半圈 | 剑身/拳头凝聚光芒，周围空气扭曲，碎石被气浪弹飞，地面龟裂纹路扩散 |
| 11-14s | 双方同时释放最强一击。力量正面对撞——多重力叠加爆发，连环爆响，冲击波层层递进。一方力量被压制，能量溃散，连人被轰飞 | 侧面全景拍对撞轨迹，碰撞瞬间快速推近至碰撞点，冲击波推向镜头产生震屏 | 剑气化龙/化弧正面碰撞，爆出巨大冲击波与白光，山体崩塌，云层被撕裂 |
| 14-15s | 烟尘散去，败者武器脱手旋转落地/口喷鲜血倒飞，胜者收剑背身。战场满目疮痍 | 从背后仰拍胜者，前景是落地的武器，慢镜余波 | 余波气浪渐消，碎石缓缓落地，地面焦痕遍布，远处山体裂痕 |

### prompt 示例

```
3D国漫CGI风格，悬崖山巅，云海翻涌，黄昏逆光，
青衫长剑修士与黑袍持刃魔修隔空对峙，
0-3s：双方灵压外溢使地面碎石悬浮飘起、衣袂翻飞，水面荡漾涟漪，青衫修士率先拔剑冲锋，剑破空发出尖啸，中景缓慢推近至面部特写后急速跟拍冲锋；
3-7s：剑刃高速碰撞交锋攻守快速转换，每次碰撞迸发灵力光弧与火花，剑气轨迹残留空中，碰撞点特写快切多角度交替，地面裂痕逐渐扩散，空气震荡，黑袍魔修力量越打越重逐渐压制青衫修士；
7-11s：青衫修士被压制后退滑行留下地面裂痕，怒而凝气蓄力，剑身凝聚金色光芒，元气暴走周身气流旋转，慢动作定格蓄力瞬间，低角度仰拍环绕跟拍半圈，周围空气扭曲碎石被气浪弹飞；
11-14s：双方同时释放最强一击，剑气化龙正面对撞，多重力叠加爆发连环爆响，冲击波层层递进，侧面全景拍对撞轨迹后快速推近至碰撞点，冲击波推向镜头产生震屏，爆裂白光吞没画面，山体崩塌云层被撕裂；
14-15s：烟尘散去，魔修鬼头刀脱手旋转落地，青衫修士收剑背身，从背后仰拍前景是落地的鬼头刀，余波气浪渐消碎石缓缓落地，地面焦痕遍布，
金色剑气与暗紫魔气对撞色，黄昏逆光勾勒人物轮廓，16:9横屏，3D国漫CGI风格
```

## 一人破阵

**核心叙事**：孤身入阵 → 围困苦战（幻影不断重生）→ 识破阵眼 → 集中灵力一击破阵 → 连锁崩溃

**打击感模式**：连环递进 + 环境连锁

**参考原典**：
- 牧神记秦牧杀出天魔众村庄：双手交错轰出滔天巨浪，少保剑在长河中闪电般刺杀，基础剑式极尽完美
- 诛仙张小凡魔化暴走：烧火棍红芒大盛，双目赤红，招招取人性命
- 牧神记秦牧破阵：元气控剑施展云剑式，宝剑环绕周身飞行画出圆环

### 15s beat 结构（单段）

| 时间段 | 动作 | 镜头 | 能量与环境反馈 |
|---|---|---|---|
| 0-3s | 主角踏入阵法范围，地面符文逐一亮起紫光围困，多个半透明幻影敌人凭空出现 | 俯拍全场展示阵法范围，随后降至主角肩后视角 | 符文从地面浮起发紫光，空气被阵法灵力扭曲 |
| 3-7s | 主角在围攻中穿梭战斗，剑光连闪击破幻影。基础剑式（刺/挑/斩/云）极尽完美，每击精准致命。但幻影碎裂后从符文重生 | 快速跟拍穿梭，幻影被击破时碎裂成光粒子，重生时从符文再凝聚 | 每次击破幻影爆出光粒子消散，重生时从符文再凝聚，地面符文越发明亮 |
| 7-11s | 主角识破阵眼位置，集中灵力于剑尖，灵力汇聚形成耀眼白光。御剑升空拖出光尾，随后俯冲向阵眼核心 | 先仰拍升空，再转俯冲第一人称视角冲向地面阵眼 | 灵力汇聚剑尖形成耀眼白光，升空时拖出光尾，周围空气被灵力扭曲 |
| 11-14s | 剑尖刺入阵眼核心，阵眼碎裂引发连锁崩溃。符文从核心向外逐个爆裂化为光点四散，冲击波横扫全场 | 俯拍阵法全景，连锁崩溃从中心向外扩散，镜头微颤 | 连锁爆裂，紫色符文碎裂化为漫天光点，冲击波横扫全场，地面被掀翻 |
| 14-15s | 阵法消散，主角落地收剑，身后碎片如雨落下 | 背跟拍落地，慢镜展示碎片飘落 | 阵法残留光点如萤火虫般飘散消逝，地面焦痕呈阵法形状 |

### prompt 示例

```
3D国漫CGI风格，古战场遗迹，地面刻满符文，黄昏氛围，
白衣剑修独自面对阵法围困，
0-3s：白衣剑修踏入阵法范围，地面符文逐一亮起紫光围困，多个半透明幻影敌人凭空出现，俯拍全场展示阵法规模后降至肩后视角，空气被阵法灵力扭曲；
3-7s：剑修在围攻中穿梭战斗，剑光连闪击破幻影，刺剑式挑剑式斩剑式云剑式极尽完美每击精准致命，幻影碎裂成光粒子但不断从符文重生，快速跟拍穿梭，地面符文越发明亮；
7-11s：剑修识破阵眼，集中灵力于剑尖形成耀眼白光，御剑升空拖出光尾，先仰拍升空再转俯冲第一人称视角冲向地面阵眼，周围空气被灵力扭曲；
11-14s：剑尖刺入阵眼核心，阵眼碎裂引发连锁崩溃，紫色符文从中心向外逐个爆裂化为漫天光点四散，冲击波横扫全场，俯拍阵法全景展示连锁扩散，镜头微颤，地面被掀翻；
14-15s：阵法消散，剑修落地收剑，身后碎片如雨落下，阵法残留光点如萤火虫飘散消逝，背跟拍慢镜展示碎片飘落，地面焦痕呈阵法形状，
紫色与白色能量交织，体积光穿透云层照亮战场，16:9横屏，3D国漫CGI风格
```

## 法术对轰

**核心叙事**：拉开距离 → 各自蓄法 → 能量膨胀至极限 → 正面对撞 → 一方碾压轰飞

**打击感模式**：单重爆发 + 空间扭曲

**参考原典**：
- 诛仙陆雪琪神剑御雷真诀：九天玄刹化为神雷，煌煌天威以剑引之
- 诛仙诛仙剑阵主剑天降：七彩巨剑横亘苍穹，带着开天破地之势隆隆冲下
- 牧神记秦牧元气暴走：体内元气澎湃激荡，杀猪刀与元气共鸣铮鸣跃起

### 15s beat 结构（单段）

| 时间段 | 动作 | 镜头 | 能量与环境反馈 |
|---|---|---|---|
| 0-3s | 双方拉开距离对峙，同时结印施法。手掌间凝聚不同属性能量球——一方蓝白灵力球，一方赤红烈焰球 | 双人对称构图，缓慢推近至手部特写 | 能量球初现，周围空气开始扭曲，地面碎石微微震动 |
| 3-7s | 能量球急速膨胀至人身大小，环境剧烈反应——地面龟裂纹路扩散、雷电环绕能量球聚集、碎石悬浮。慢镜展示蓄力过程 | 从手部特写拉至全景展示环境影响，慢动作 | 能量球膨胀至人身大小，地面龟裂纹路扩散，雷电环绕，碎石悬浮，空气扭曲 |
| 7-11s | 双方同时推出能量，两道能量束在空中高速对撞。碰撞点爆出剧烈白光闪与能量涟漪，空间在碰撞点出现裂缝 | 侧面全景拍对撞轨迹，碰撞瞬间快速推近至碰撞点 | 两道能量束在中间点碰撞，耀眼白光闪，碰撞点空间出现裂缝，能量涟漪扩散 |
| 11-14s | 对撞点产生扩散冲击波横扫全场。一方能量被压制推回，连人一起被轰飞。环境被冲击波撕裂——树木折断、地面掀翻 | 镜头跟随被轰飞方快速后移，环境被冲击波撕裂 | 冲击波横扫，树木折断地面掀翻，败方身上能量溃散，空气如热浪扭曲 |
| 14-15s | 爆炸余波消散，胜者收掌站立，败者倒地。战场焦痕遍布，余烬微光闪烁 | 俯拍战场全景展示破坏痕迹 | 余波能量如热浪扭曲空气，焦痕处残留余烬微光 |

### prompt 示例

```
3D国漫CGI风格，荒野平原，雷云密布，风云变色，
道袍修士与血衣邪修拉开距离对峙施法，
0-3s：双方同时结印施法，道袍修士手掌间凝聚蓝白灵力球，血衣邪修凝聚赤红烈焰球，双人对称构图缓慢推近至手部特写，周围空气开始扭曲，地面碎石微微震动；
3-7s：能量球急速膨胀至人身大小，地面龟裂纹路扩散，雷电环绕能量球聚集，碎石悬浮，慢动作展示蓄力过程，从手部特写拉至全景展示环境影响；
7-11s：双方同时推出能量，蓝白灵力束与赤红烈焰束在空中高速对撞，碰撞点爆出剧烈白光闪与能量涟漪，碰撞点空间出现裂缝，侧面全景拍对撞轨迹后快速推近至碰撞点；
11-14s：对撞点产生扩散冲击波横扫全场，赤红能量被压制推回，血衣邪修连人一起被轰飞，树木折断地面掀翻，镜头跟随被轰飞方快速后移，败方身上能量溃散，空气如热浪扭曲；
14-15s：爆炸余波消散，道袍修士收掌站立，血衣邪修倒地，战场焦痕遍布余烬微光闪烁，俯拍全景展示破坏痕迹，
蓝白灵力与赤红烈焰对撞色，雷电照亮战场，16:9横屏，3D国漫CGI风格
```

## 剑阵决战

**核心叙事**：阵法展开（七脉灵力汇聚）→ 万剑齐发（漫天剑雨）→ 主剑天降（开天破地）→ 抵挡/破阵 → 余波天地变色

**打击感模式**：天威碾压 + 漫天剑雨

**参考原典**：
- 诛仙青云山诛仙剑阵：七色光芒融为一体，化作巨大七色巨剑，满天单色气剑密密麻麻如云雾，主剑带着开天破地之势隆隆冲下
- 诛仙道玄催动剑阵：左手剑诀挥动直刺天际，六色光芒从各峰升腾如长虹贯穿天际，七色合一
- 诛仙碧瑶痴情咒挡剑：九幽阴灵诸天神魔以我血躯奉为牺牲，狂风变为围绕碧瑶的巨大漩涡

### 15s beat 结构（单段）

| 时间段 | 动作 | 镜头 | 能量与环境反馈 |
|---|---|---|---|
| 0-3s | 施阵者持古剑刺天，口中低颂咒语。周围山峰灵力升腾如长虹贯穿天际，七色光芒汇聚于古剑之上 | 仰拍施阵者持剑刺天，随后转俯拍展示灵力从各方向汇聚 | 七色光芒从远处山峰升腾如长虹，汇聚于古剑之上，天地间灵气翻涌 |
| 3-7s | 天空中七色巨剑成形，横亘苍穹。从主剑上分离出无数单色气剑，密密麻麻布满天空。气剑如雨般锐啸而下，覆盖全场 | 仰拍漫天剑雨，跟拍单剑俯冲轨迹 | 七色巨剑横亘苍穹，满天气剑如云雾，锐啸而下，地面被气剑轰出密集弹坑 |
| 7-11s | 主剑带着开天破地之势隆隆冲下。被攻击方集中全部力量抵挡/施展底牌——凝聚护盾/以身为盾/释放最强反击。主剑降临的压迫感使空间凝滞 | 从主剑视角俯冲下坠，转地面仰拍接主剑降临 | 主剑体积遮天蔽日，隆隆轰鸣，被攻击方附近地面尽数迸裂，狂风呼啸 |
| 11-14s | 主剑击中，剧烈爆炸。被攻击方或被碾压倒下，或拼死挡住/破开剑阵。碰撞产生巨大冲击波，天地变色 | 碰撞点全景，冲击波扩散推向镜头震屏 | 剧烈白光爆裂，冲击波横扫，天地变色，地面大面积崩塌，云层被撕开 |
| 14-15s | 余波消散，胜者持剑悬立空中/败者倒地。战场面目全非，远处山体崩塌 | 俯拍全景，慢镜展示破坏痕迹 | 漫天残余气剑化为光点消散，焦痕遍布，余烬飘散 |

### prompt 示例

```
3D国漫CGI风格，通天峰山巅，雷云密布，风云呼啸，
道袍长者持诛仙古剑刺天催动剑阵，
0-3s：道袍长者持古剑刺天低颂咒语，周围山峰灵力升腾如长虹贯穿天际，七色光芒汇聚于古剑之上，仰拍持剑刺天后转俯拍展示灵力从各方向汇聚，天地间灵气翻涌；
3-7s：天空中七色巨剑成形横亘苍穹，从主剑分离出无数单色气剑密密麻麻布满天空，气剑如雨般锐啸而下覆盖全场，仰拍漫天剑雨跟拍单剑俯冲轨迹，地面被气剑轰出密集弹坑；
```

## 情感对决

**核心叙事**：武器先于主人感应 → 下手无情交锋（共鸣爆裂） → 底牌全开（终极招式对撞） → 同归同伤碰撞 → 情绪余韵

**打击感模式**：相克共鸣 + 情感拉扯 + 情绪外化

**通用适用条件**（满足任一即可触发情感对决编排）：
- 战斗双方有情感羁绊（师出同门/旧友/正邪对立但有牵绊/宿敌存知音之意）
- 双方武器/法宝存在相克或宿缘关系
- 用户明确要求"又打又虐""下手狠但有感情""相爱相杀"等情感战斗基调
- 碰撞结局为同归同伤或两败俱伤而非一方胜

**参考原典**（打击感逻辑参考，非锁定角色）：
- 诛仙七脉会武：烧火棍黑气蒸腾青光大盛，天琊蓝光闪烁，两件法宝空中碰撞互相弹开，双方身子大震，擂台被拆成碎片
- 诛仙七里峒：天琊蓝光漫天席地呼啸而来，噬血珠红芒万丈如恶鬼啸天，红蓝激斗
- 诛仙天帝宝库前：神剑御雷真诀引九天神雷，三家真法融合硬接

### 与普通双人对决的核心区别

| 维度 | 普通双人对决 | 情感对决 |
|---|---|---|
| 碰撞结果 | 一方胜一方败 | 双方同时震动倒退（同归同伤） |
| 武器关系 | 无特殊 | 相克武器共鸣爆裂，碰撞比正常更剧烈 |
| 情感基调 | 仇恨/胜负 | 下手越狠情感越深（无情即深情） |
| 收束方式 | 败者倒地，胜者收势 | 双方分开各自喘息，武器仍颤动呼应 |
| 环境反馈 | 战斗波及环境 | 环境被"拆毁"——擂台如纸屑四散 |
| 面部刻画 | 不强调 | 双方表情对比呈现（冷 vs 狂、痛 vs 决），眼神交汇有情感暗流 |
| 情绪弧线 | 不强调 | 有明确演变弧线（如犹豫→坚定→释然） |

### 15s beat 结构（单段）

| 时间段 | 动作 | 镜头 | 能量与环境反馈 | 情绪/表情 |
|---|---|---|---|---|
| 0-3s | 双方对峙，手中武器先于主人感应——武器自行颤动嗡鸣，光芒异变。随后双方同时出手 | 双武器特写交替（武器共鸣运镜），后切双方面部对切 | 武器光芒初现异变，嗡鸣声 | 冷静审视中透出复杂、目光交汇一瞬后移开 |
| 3-7s | 双方武器在半空高速碰撞交锋。每次碰撞产生共鸣爆裂——比普通碰撞更剧烈，双方同时被震退。碰撞余波将周围环境拆毁 | 碰撞点特写快切多角度，环境碎片飞过镜头 | 双色光芒交织缠绕爆裂，共鸣冲击波，环境被拆毁碎片四散 | 出手时面部冷厉/狰狞交替，眼神在出手瞬间闪过犹豫或决绝 |
| 7-11s | 一方施展终极招式（引天雷/万剑/极限功法），另一方以全力硬接 | 仰拍终极招式冲天而起，转俯拍击下，慢镜展示另一方面部 | 终极招式能量与场景深度互动（天雷劈开云层/万剑轰碎地面/地面大面积崩裂） | 决绝的冷峻 vs 咬牙的疯狂，眼神交汇中透出复杂情感 |
| 11-14s | 最强一击正面碰撞，剧烈爆裂后双方同时吐血倒退飞出 | 侧面全景拍对撞，推近至碰撞点，双方同时吐血倒退跟拍慢镜 | 双色光芒爆裂交织，巨大冲击波横扫，地面崩裂/环境拆毁 | 碰撞瞬间双方面部痛苦一瞬，但目光未退 |

- 情绪弧线跨段延续：第1段的情绪在碰撞时达到顶峰，第2段从痛苦/不甘接续，最终走向释然/疲惫/决绝

## 综合混合

当用户未指定单一战斗类型或描述中包含多种元素时，从上述五种方案中择 1-2 种组合：

**组合策略**：
- 双人对决 + 法术对轰：先近战交锋摸底，再拉开距离法术对轰，最后决胜一击
- 一人破阵 + 双人对决：破阵过程中与阵主/守阵者交锋，边打边破阵
- 法术对轰 + 剑阵决战：先法术对轰，一方祭出剑阵决战，另一方以法术破阵
- 双人对决 + 剑阵决战：近战交锋后一方开启剑阵碾压，另一方以一人之力破阵
- 情感对决 + 剑阵决战：情感对决中一方祭出剑阵碾压，另一方以一人之力破阵后两败俱伤

组合时仍保持因果链逻辑：试探 → 升级 → 转折 → 决胜 → 收束。

## 打击感节奏模式

> 从牧神记和诛仙的战斗描写中提炼的打击感节奏方案，可直接注入 prompt。

### 模式一：多重力叠加（牧神记·九龙驭风雷）

```

第二重双龙绞缠，两股力量纠缠钻入；

```

```

```

## 落 prompt 前自检

- [ ] 每个 beat 是否同时包含动作 + 镜头 + 能量/环境反馈三要素
- [ ] 是否有快慢节奏交替（慢动作定格 + 高速交锋）
- [ ] 环境是否有互动反馈（地面碎裂/云层撕裂/树木折断/擂台拆碎等）
- [ ] 冲击波/能量碰撞是否有镜头反馈（震屏/光闪/气浪）

- [ ] 力量等级差是否通过环境破坏程度体现（不是靠角色喊出来）
- [ ] 每个 beat 是否包含角色情绪/表情/眼神描述
- [ ] 情绪是否有演变弧线（不是从头到尾同一表情）
- [ ] 角色与环境是否有互动（灵压影响碎石/冲击波拆毁擂台/花瓣被气浪卷起等）
