# 平台与生成执行

仅在用户要求制作视频、指定平台或需要实际素材接口时读取。本文不绑定某个供应商，不声明不存在的工具，也不把平台参数写成创作规则。

## 能力确认

从当前可调用工具的说明、接口返回或平台官方文档核实本次需要的能力，不依赖旧记忆猜测参数：

| 项目 | 需要确认的内容 |
|---|---|
| 执行入口 | 工具实际存在、输入结构、登录或连接是否可用 |
| 时长 | 单次最短与最长时长、离散可选值、是否允许延长或裁切 |
| 画面 | 支持的画幅、分辨率及风格约束 |
| 镜头模式 | 单镜、多镜或自定义分镜开关的实际含义；多轮攻防不等于多镜头，不能因动作多就擅自开启自动切镜 |
| 素材 | 图片、首尾帧、角色参考或视频参考的支持情况和标识语法 |
| 动作迁移 | 当前模式实际传递身体、表情、相机还是场景；角色图与角色视频的控制范围是否不同，目标交互是否在已支持范围内 |
| 声音 | 是否生成音频、对白与音效怎样输入、能否关闭声音；需要音频参考时另查支持方式，不因支持图片附件就推定支持音频 |
| 异步任务 | 任务编号、查询方式、成功和失败状态、结果有效期 |
| 后处理 | 拼接、裁切、变速、停格、转场与音轨处理能力；改变帧率是否改变时间轴，音频如何随变速处理 |
| 提示词形式 | 自然动作顺序、粗时间窗、结构化分镜或独立排除字段的实际支持情况；分段控制的数值是秒、帧还是相对权重，控制边界是否仅影响生成条件而非实际切镜 |
| 请求长度 | 当前模型与工具各自的长度上限、计量单位，以及超限时拒绝还是截断；关键动作与结局是否仍在实际发送范围内 |
| 测试预算 | 用户授权的总额与币种、已确认消耗、未结算任务及本次设置的报价；账户余额不等于本任务的授权额度 |

只检查影响本次任务的项目。明确要求生成且已有授权时继续，不额外增加重复审批；仅要求写提示词时不启动生成。

要求后期变速时，确认工具改变的是播放时间还是只重采样帧率，并核对最终使用时长；声音随画面变速、保持音高或单独重新配音是不同处理，按要求及实际能力选择。若只完成画面变速，不把未处理或未听辨的音轨记为已经同步。

创作中的声音要求与实际制作能力分开。无原生音频能力时，可按已确认的后期能力处理，不能承诺原生成声音；也不因社区模板写着“后期添加”，便断言当前平台不能生成声音。音频参考、分轨编辑、口型和精确卡点均不能凭提示词文字保证，不自动制作或上传未被需要的控制音轨。只有文案任务时，保留用户的声音意图即可。

能接收视频不等于当前模式能复刻其中的全身打斗。实际执行前核对参考的职责、输入组合和控制开关；不要把特效预设、表情驱动、身份参考和动作迁移混用。只支持局部表情控制的模式不能据此承诺重新生成双人兵刃接触；接口支持相应动作输入时，也仍需检查实际输出，不能以素材上传成功代替动作核验。

平台适配以当前官方说明与实际接口为准，不继承社区技能中未经核实的模型参数。比如 [Runway 图生视频指南](https://help.runwayml.com/hc/en-us/articles/48324313115155-Image-to-Video-Prompting-Guide)侧重描述输入图之后的运动；[Google 视频提示词指南](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/video/video-gen-prompt-guide)讨论了声音与排除提示。这些建议适用于各自文档的模型与模式，不能互相代替。能力会变化，每次实际执行仍需核实；正文正向描述优先，独立排除字段仅在接口支持且有需要时使用。

## 执行与停止条件

1. 按平台实际能力把成片时间轴映射为生成片段。准确记录每段生成时长与最终使用时长，不能把延长或裁切假设当成已有能力。
2. 按本次请求核对提示词中的素材编号或名称与实际附件、顺序及职责；替换、重排或移除素材后同步引用，不沿用旧请求的绑定。提交实际素材与提示词，保存返回的任务编号和状态。提交成功只表示任务被接受。
3. 按工具建议查询任务，出现明确失败则读取原因。修正确定的参数错误后，在已有授权和剩余预算内可重试一次；认证失败、余额不足、持续服务故障时停止并说明所需处理。
4. 提交超时且任务是否创建不明时，先查询已有任务或使用接口支持的幂等机制。无法确认时停止，不盲目重复提交可能产生重复任务的请求。
5. 成功后取得实际文件或可用结果链接，按已确认能力完成拼接、裁切和声音处理。工具未提供相应能力时交付已有分段及待完成项。
6. 能查看视频时检查身份、持械、来路与接触、法阵功能、地形延续、节奏与音画。区分缺陷位置与可能原因，不将模型漏拍直接判成提示词规则有效。

每次付费提交前按本次实际设置核对报价与剩余授权；更换模型、增加声音、重试或另开批次不会重置总预算。未确认的退款不计回余额，未结算的任务保留可能占用的额度；费用上限无法确定时不以猜测继续提交。用户已限定仅免费调研时，即使账户或预算还有余额，也不发起付费任务，不反复请求追加预算。

任务进度百分比不是成片观察。接近完成后长时间不变，不能单凭这一现象归因于动作没有终点，更不能擅自改成停下、回到起点后重复付费提交；先核对原任务状态、错误信息及服务说明，再处理有证据的问题。

若请求修正失败成片，按 [素材与迭代](reference-and-iteration.md) 先记录可观察症状，再选择有界的调整范围，必要时联动修正直接依赖项。仅有用户描述而没有可观看文件时，将原因标为待验证假设。

不要为了满足“必须有 MP4”的文字要求虚构路径、成功状态或下载链接。没有视频查看能力时，注明文件取得但内容尚未观看核验。

## 交付状态

| 实际进度 | 可以声明 | 仍未证明 |
|---|---|---|
| 提示词与时间轴完成 | 文本编排完成 | 视频存在、模型执行效果 |
| 任务提交并返回编号 | 生成任务已提交 | 已生成成功 |
| 工具返回成功且结果可取得 | 视频生成完成 | 动作、空间、审美质量通过 |
| 已观看并记录具体结果，有声任务另记听辨范围 | 本次样片已审阅，列出检查范围、通过项与缺陷 | 未听辨部分的音画质量、其他输入或模型同样稳定 |

## 无法生成时

交付完整可复用提示词、分段时长、素材映射与接续状态，以及工具缺失或失败的准确原因。用户仅要求提示词时，不必附带生成环境说明。用户明确指定的平台不可用时，不擅自换平台执行。
