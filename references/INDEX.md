# 参考导航

普通任务先使用 [技能主体](../SKILL.md)，按当前问题选择参考；组合场景可读取多份，仍按同一攻防过程编排。

## 创作时按需读取

| 文件 | 使用时机 |
|---|---|
| [战斗编排](formats/combat-choreography.md) | 战斗目标、近战连招与变招、反转、受力与恢复、诱招、压抵、擒拿与抛掷、缴械、节奏强度与情感选择 |
| [移动与在途攻击](formats/movement-and-projectiles.md) | 轻功、御剑与御空、瞬移、地形通行、实体兵器往返、停射和术法中断 |
| [力量与法阵](formats/powers-and-formations.md) | 屏障结果、力量叠加、境界压制、功法融合、属性相克、体型差、法阵附着与破阵推理 |
| [分身与多人协同](formats/clones-and-multi-combat.md) | 分身与幻影的数量、能力和退场，多人持续施压与同步接触 |
| [视频提示词文法](formats/video-prompt-grammar.md) | CGI 与真人质感、时长、景别与运镜、画幅及竖屏适配、声音与吟诵、提示词压缩和跨段接续 |
| [仙侠用词](industries/xianxia-vocabulary.md) | 为已经确定的动作补充术法形态、材质、变招、施法和反馈措辞 |
| [平台与生成执行](formats/platforms-markets.md) | 用户要求实际制作视频，或需要核对指定平台及接口 |
| [素材与迭代](formats/reference-and-iteration.md) | 素材分工、分镜拼图、动作改编、身份归属、首尾帧冲突、样片观察与失败修正 |

## 维护与验证

| 文件 | 使用时机 |
|---|---|
| [文本回归案例](../examples/behavior-regression.md) | 修改技能后检查约束、时间轴、因果与接续，不作为默认模板 |

| [调研索引](../research/INDEX.md) | 按问题追溯方法来源、采用边界、公开样片观察和历史验证记录 |
